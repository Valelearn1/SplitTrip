# v3.5 «App installabile e offline» — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SplitTrip si installa sul telefono e, senza rete, mostra gli ultimi dati e le foto già visti in sola lettura, con l'avviso dell'età dei dati, la barra «Aggiorna» per le versioni nuove e tutto cancellato all'uscita dall'account.

**Architecture:** `vite-plugin-pwa` (Workbox, `generateSW`, `registerType: 'prompt'`) genera manifest e service worker: guscio dell'app, font e immagini (foto, miniature, avatar) in cache. La cache di TanStack Query si salva in IndexedDB (`persistQueryClientRestore` / `persistQueryClientSubscribe` con `idb-keyval`), marchiata con versione e id utente. Un hook `useOnline()` sopra `onlineManager` guida barra offline, controlli disattivati, segnaposti; le mutation falliscono subito offline (`networkMode: 'always'`), mai in coda.

**Tech Stack:** React 19, TypeScript, Vite 8.2.2, TanStack Query 5.104.4, `@tanstack/react-query-persist-client` 5.104.4, `@tanstack/query-async-storage-persister` 5.104.4, `idb-keyval` 6.3.0, `vite-plugin-pwa` 2.0.0, `workbox-window` 7.4.1, Vitest + Testing Library + MSW.

**Spec:** `docs/superpowers/specs/2026-10-19-v3.5-app-installabile-offline-design.md`

## Global Constraints

- Solo frontend: il backend non cambia (nessun file sotto `BE/`).
- Senza rete nessuna scrittura: né in coda né rimandata. Le mutation hanno `networkMode: 'always'` e falliscono subito.
- Il service worker non mette mai in cache JSON di `/api` né `/ws`: solo guscio, font, `.../trips/{id}/photos/{id}/(image|thumbnail)` e `.../users/{id}/avatar`.
- Persistenza: solo query `success` con chiave che inizia per `home`, `trips`, `chat`, `notifications`, `me`; `maxAge` e `gcTime` 7 giorni; `buster` = `` `${CACHE_VERSION}:${userId}` ``, `CACHE_VERSION = 1`.
- Uscita dall'account (anche dopo un 401) → `clearDeviceData()`: client svuotato, chiave IndexedDB `splittrip-cache` rimossa, cache `splittrip-foto` e `splittrip-avatar` cancellate.
- Testi esatti: «Sei offline · dati delle HH:MM», «Sei offline · dati del GG/MM alle HH:MM», «serve la rete per salvare», «Di nuovo online», «Questa pagina non è ancora salvata sul telefono: aprila una volta con la rete», «Serve la rete», «La mappa serve la rete», «Serve la rete per entrare», «Sei offline: la modifica non è stata salvata. Riprova quando torna la rete», «Sei offline: i messaggi tornano con la rete», «C'è una nuova versione di SplitTrip», «Aggiorna», «Dopo», «Installa SplitTrip», «SplitTrip è installata su questo dispositivo», «Puoi installarla dal menu del browser, se lo permette».
- Linguaggio senza genere nei testi nuovi; mai solo colore (icona + testo, D-24); bersagli da 44 px; testo fuori dalle card verificato sopra lo sfondo stagionale nei due temi.
- Service worker spento in sviluppo (`devOptions.enabled: false`); prove con `npm run build && npm run preview`.
- Nessuno script inline nuovo in `index.html` (`injectRegister: false`): l'hash CSP esistente resta valido.
- I commit li fa l'autrice: ogni task finisce con «Puoi committare: `<messaggio>`» e Stage All. Nessuna riga `Co-Authored-By`.
- Comandi dalla cartella `FE/`: test `npm test -- --run`, build `npm run build`, lint `npx eslint src`.

## Review Focus

1. Due persone sullo stesso telefono: Vale esce, Marco entra offline o online → non deve mai comparire un dato di Vale (marchio con id utente + `clearDeviceData`). Test nel Task 3.
2. La rete cade a metà salvataggio di una spesa: niente spesa doppia al ritorno della rete, il modulo resta compilato e dice perché (`networkMode: 'always'`). Test nel Task 4.
3. Avatar appena cambiato: con la cache del service worker non deve ricomparire la foto vecchia → avatar in `NetworkFirst`, non `StaleWhileRevalidate` (vedi nota sotto). Test di configurazione nel Task 1.
4. Pagina mai aperta, offline: niente spinner infinito, ma il messaggio «non ancora salvata». Test nel Task 2.
5. Una versione nuova pubblicata mentre l'app installata è aperta: barra «Aggiorna», e la pagina non si ricarica da sola a metà modulo. Test nel Task 6.

**Note rispetto alla spec (decise scrivendo il piano):**
- Al posto di `PersistQueryClientProvider` si usano `persistQueryClientRestore` + `persistQueryClientSubscribe` in un componente `DevicePersistence` dentro `AuthProvider`: il marchio dipende dall'utente, che cambia all'accesso senza ricaricare la pagina; il provider legge le opzioni una volta sola. Comportamento identico alla spec.
- Avatar con `NetworkFirst` (timeout 3 s) invece di `StaleWhileRevalidate`: con SWR, subito dopo aver cambiato foto si rivedrebbe quella vecchia. Offline il risultato è lo stesso (copia salvata).
- Il motivo «serve la rete per salvare» si legge una volta nella barra offline (sempre visibile senza rete) e i bottoni disattivati lo collegano con `aria-describedby="offline-reason"` e `title`, invece di una riga sotto ogni bottone: le file di bottoni (`.actions`) non si rompono.
- `@tanstack/react-query` sale da 5.104.2 a 5.104.4 (richiesto dal persister, solo patch).

`FE/src/features/pwa/swRoutes.ts`:
```ts
const escape = (s: string) => s.replace(/[.*+?^${}()|[\]\\/]/g, '\\$&')

/**
 * Indirizzi delle immagini che il service worker salva (D-63): foto, miniature, scontrini e avatar. Mai il JSON di /api.
 * Workbox confronta l'URL intero e serializza solo RegExp (non funzioni): per questo si costruiscono qui da VITE_API_URL.
 */
export function imageRoutes(apiUrl: string): { photos: RegExp; avatars: RegExp } {
  const trimmed = apiUrl.replace(/\/+$/, '')
  const base = /^https?:\/\//.test(trimmed) ? escape(trimmed) : `https?://[^/]+${escape(trimmed)}`
  return {
    photos: new RegExp(`^${base}/trips/[^/]+/photos/[^/]+/(image|thumbnail)$`),
    avatars: new RegExp(`^${base}/users/[^/]+/avatar$`),
  }
}
```

/// <reference types="vitest/config" />
import { fileURLToPath, URL } from 'node:url'
import react from '@vitejs/plugin-react'
import { defineConfig, loadEnv } from 'vite'
import { VitePWA } from 'vite-plugin-pwa'
import { manifest } from './src/features/pwa/manifest'
import { imageRoutes } from './src/features/pwa/swRoutes'

const DAY = 24 * 60 * 60

export default defineConfig(({ mode }) => {
  const { photos, avatars } = imageRoutes(loadEnv(mode, process.cwd(), '').VITE_API_URL ?? '/api')
  return {
    plugins: [
      react(),
      // D-63: app installabile, guscio e immagini già viste offline; il JSON di /api non passa mai dalla cache
      VitePWA({
        registerType: 'prompt',
        injectRegister: false,
        manifest,
        includeAssets: ['favicon.svg', 'apple-touch-icon.png'],
        devOptions: { enabled: false },
        workbox: {
          globPatterns: ['**/*.{js,css,html,svg,png,webmanifest}'],
          navigateFallback: '/index.html',
          navigateFallbackDenylist: [/^\/api\//, /^\/ws/],
          cleanupOutdatedCaches: true,
          runtimeCaching: [
            { urlPattern: /^https:\/\/fonts\.googleapis\.com\/.*/, handler: 'StaleWhileRevalidate',
              options: { cacheName: 'splittrip-font-css', expiration: { maxEntries: 10 } } },
            { urlPattern: /^https:\/\/fonts\.gstatic\.com\/.*/, handler: 'CacheFirst',
              options: { cacheName: 'splittrip-font', expiration: { maxEntries: 30, maxAgeSeconds: 365 * DAY }, cacheableResponse: { statuses: [0, 200] } } },
            { urlPattern: photos, handler: 'CacheFirst',   // una foto caricata non cambia più
              options: { cacheName: 'splittrip-foto', expiration: { maxEntries: 150, maxAgeSeconds: 30 * DAY }, cacheableResponse: { statuses: [200] }, matchOptions: { ignoreVary: true } } },
            { urlPattern: avatars, handler: 'NetworkFirst', // l'avatar cambia: online sempre quello nuovo, offline la copia
              options: { cacheName: 'splittrip-avatar', networkTimeoutSeconds: 3, expiration: { maxEntries: 60, maxAgeSeconds: 30 * DAY }, cacheableResponse: { statuses: [200] }, matchOptions: { ignoreVary: true } } },
          ],
        },
      }),
    ],
    server: {
      proxy: { '/api': 'http://localhost:8080', '/ws': { target: 'ws://localhost:8080', ws: true } },
    },
    test: {
      environment: 'jsdom',
      globals: true,
      setupFiles: './src/test/setup.ts',
      css: false,
      env: { VITE_API_URL: 'http://localhost/api' },
      alias: { 'virtual:pwa-register/react': fileURLToPath(new URL('./src/test/pwaRegisterStub.ts', import.meta.url)) },

import type { QueryCache } from '@tanstack/react-query'

const two = (n: number) => String(n).padStart(2, '0')

/** «Sei offline · dati delle 21:40», o con la data se non sono di oggi: l'età onesta di ciò che si vede (D-63). */
export function dataAgeLabel(oldest: number | null, now: Date = new Date()): string {
  if (!oldest) return 'Sei offline'
  const d = new Date(oldest)
  const time = `${two(d.getHours())}:${two(d.getMinutes())}`
  return d.toDateString() === now.toDateString()
    ? `Sei offline · dati delle ${time}`
    : `Sei offline · dati del ${two(d.getDate())}/${two(d.getMonth() + 1)} alle ${time}`
}

/** Il dato più vecchio tra le query che la pagina sta mostrando (quelle con osservatori). */
export function oldestActiveData(cache: QueryCache): number | null {
  const times = cache.findAll({ type: 'active' }).map((q) => q.state.dataUpdatedAt).filter((t) => t > 0)
  return times.length > 0 ? Math.min(...times) : null
}

export function OfflineBanner() {

  const cache = useQueryClient().getQueryCache()
  const oldest = useSyncExternalStore((notify) => cache.subscribe(notify), () => oldestActiveData(cache), () => null)
  const [wasOffline, setWasOffline] = useState(!online)
  const [back, setBack] = useState(false)
  if (!online && !wasOffline) setWasOffline(true)
  if (online && wasOffline) { setWasOffline(false); setBack(true) }
  useEffect(() => {
    if (!back) return
    const t = setTimeout(() => setBack(false), 3000)
    return () => clearTimeout(t)
  }, [back])

        <Icon name="cloud_off" />

      </div>
    )
  }
  if (back) return <div className="offline-banner back" role="status"><Icon name="cloud_done" /><span>Di nuovo online</span></div>
  return null
}

import { createAsyncStoragePersister } from '@tanstack/query-async-storage-persister'
import type { Query } from '@tanstack/react-query'
import { del, get, set } from 'idb-keyval'

/** Da aumentare a mano quando cambia la forma dei dati dell'API: la copia vecchia sul telefono si scarta (D-63). */
export const CACHE_VERSION = 1
export const CACHE_KEY = 'splittrip-cache'
export const MAX_AGE = 7 * 24 * 60 * 60 * 1000

const PERSISTED = new Set(['home', 'trips', 'chat', 'notifications', 'me'])

/** Solo dati riusciti e utili offline: mai immagini (cache del service worker), AI, anteprime d'invito. */
export function shouldPersist(query: Query): boolean {
  const head = query.queryKey[0]
  return query.state.status === 'success' && typeof head === 'string' && PERSISTED.has(head)
}

export const busterFor = (userId: string) => `${CACHE_VERSION}:${userId}`

export const persister = createAsyncStoragePersister({
  storage: { getItem: (k) => get<string>(k).then((v) => v ?? null), setItem: (k, v) => set(k, v), removeItem: (k) => del(k) },
  key: CACHE_KEY,
  throttleTime: 1000,
})

`FE/src/features/pwa/DevicePersistence.tsx`:
```tsx
import { useQueryClient } from '@tanstack/react-query'
import { persistQueryClientRestore, persistQueryClientSubscribe } from '@tanstack/react-query-persist-client'
import { useEffect, useState, type ReactNode } from 'react'
import { useAuth } from '../auth/useAuth'
import { busterFor, MAX_AGE, persister, shouldPersist } from './persistence'

/**
 * Per l'utente che ha fatto l'accesso: prima ripristina la copia salvata sul telefono, poi la tiene aggiornata (D-63).
 * Il marchio contiene l'id: la copia di un'altra persona si scarta invece di comparire. Senza accesso non salva nulla.
 */
export function DevicePersistence({ children }: { children: ReactNode }) {
  const { auth } = useAuth()
  const client = useQueryClient()
  const userId = auth?.user.id
  const [restoredFor, setRestoredFor] = useState<string | null>(null)

  useEffect(() => {
    if (!userId) return
    let alive = true
    let unsubscribe = () => {}
    const buster = busterFor(userId)
    persistQueryClientRestore({ queryClient: client, persister, buster, maxAge: MAX_AGE })
      .catch(() => console.warn('Copia offline non disponibile su questo dispositivo'))   // IndexedDB assente o piena: si va avanti online
      .finally(() => {
        if (!alive) return
        unsubscribe = persistQueryClientSubscribe({ queryClient: client, persister, buster, dehydrateOptions: { shouldDehydrateQuery: shouldPersist } })
        setRestoredFor(userId)
      })
    return () => { alive = false; unsubscribe() }
  }, [client, userId])

  if (userId && restoredFor !== userId) return null   // pochi millisecondi: niente richieste prima del ripristino
  return children
}
```

type Props = { path: string; alt: string; className?: string }

/** <img> per immagini che richiedono il Bearer: scarica il blob (in cache di TanStack Query) e lo mostra con un object URL. */
export function AuthImage({ path, alt, className = '' }: Props) {
  const online = useOnline()
  // offlineFirst (D-63): anche senza rete si prova, e il service worker risponde con la copia salvata se c'è
  const { data, isError } = useQuery({
    queryKey: ['blob', path], queryFn: () => apiBlob(path), staleTime: Infinity, gcTime: 10 * 60_000,
    networkMode: 'offlineFirst', retry: (failures) => onlineManager.isOnline() && failures < 1,
  })
  const url = useMemo(() => (data ? URL.createObjectURL(data) : undefined), [data])
  useEffect(() => () => { if (url) URL.revokeObjectURL(url) }, [url])
  if (!url && isError && !online) {
    return (
      <span className={`img-placeholder img-offline ${className}`} role="img" aria-label={`${alt}: serve la rete`}>
        <Icon name="image_not_supported" /><small>Serve la rete</small>
      </span>
    )
  }
  if (!url) return <span className={`img-placeholder ${className}`} role="img" aria-label={alt} aria-busy="true" />
  return <img src={url} alt={alt} className={className} />
}

```ts
type InstallEvent = Event & { prompt: () => Promise<void>; userChoice: Promise<{ outcome: 'accepted' | 'dismissed' }> }
export type InstallMode = 'installed' | 'prompt' | 'ios' | 'menu'

/** L'evento di installazione arriva una volta, presto: lo si tiene finché il Profilo lo usa (D-63). */
export function createInstallStore() {
  let deferred: InstallEvent | null = null
  let installed = false
  let version = 0
  const listeners = new Set<() => void>()
  const emit = () => { version++; listeners.forEach((l) => l()) }
  return {
    listen(target: EventTarget) {
      target.addEventListener('beforeinstallprompt', (e) => { e.preventDefault(); deferred = e as InstallEvent; emit() })
      target.addEventListener('appinstalled', () => { deferred = null; installed = true; emit() })
    },
    subscribe(l: () => void) { listeners.add(l); return () => { listeners.delete(l) } },
    version: () => version,
    hasPrompt: () => deferred !== null,
    installed: () => installed,
    async prompt() {
      const e = deferred
      if (!e) return
      await e.prompt()
      const { outcome } = await e.userChoice
      deferred = null
      if (outcome === 'accepted') installed = true
      emit()
    },
  }
}
export type InstallStore = ReturnType<typeof createInstallStore>
export const installStore = createInstallStore()

export function isIos(ua: string = navigator.userAgent, maxTouchPoints: number = navigator.maxTouchPoints): boolean {
  return /iPhone|iPad|iPod/.test(ua) || (/Macintosh/.test(ua) && maxTouchPoints > 1)   // l'iPad si presenta come Mac
}

export function isStandalone(): boolean {
  return window.matchMedia?.('(display-mode: standalone)').matches || (navigator as Navigator & { standalone?: boolean }).standalone === true
}

export function installMode(s: { installed: boolean; standalone: boolean; hasPrompt: boolean; ios: boolean }): InstallMode {
  if (s.installed || s.standalone) return 'installed'
  if (s.hasPrompt) return 'prompt'
  return s.ios ? 'ios' : 'menu'
}
```
