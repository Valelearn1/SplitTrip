# SplitTrip v1 Core — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pubblicare la v1 di SplitTrip: registrazione e login JWT, viaggi con codice invito, spese (divisione equa e personalizzata), rimborsi, saldi con trasferimenti suggeriti, cestino spese, Swagger, test, deploy su Render, README.

**Architecture:** Monolite Spring Boot organizzato per funzionalità (`auth`, `user`, `trip`, `expense`, `common`), ognuna con controller → service → repository e DTO record. I saldi sono calcolati al volo da una classe pura (`BalanceCalculator`). Frontend React con feature folders speculari, React Router per le pagine, TanStack Query per i dati dal server, un solo Context per l'utente loggato.

**Tech Stack:** Java 25, Spring Boot 4.1.1 (WebMVC, Data JPA/Hibernate 7.4, Security 7.1 con OAuth2 Resource Server per i JWT HS256, Validation, Actuator, Flyway 12), PostgreSQL 16, springdoc-openapi 3.1.1, JUnit 5 + Mockito + Testcontainers 2 + MockMvc. React 19, TypeScript 6, Vite 8, React Router 7, TanStack Query 5, React Hook Form + Zod 4, date-fns 4, Vitest + Testing Library + MSW. Render (Docker web service, static site, Postgres).

**Spec:** `docs/superpowers/specs/2026-10-12-splittrip-design.md` (sezioni 1–11). Questo piano copre solo la **v1 Core** (spec §2); v2 e v3 avranno piani separati.

## Global Constraints

- Importi: `NUMERIC(12,2)` nel DB, `BigDecimal` in Java con scala 2 e `RoundingMode.HALF_UP`; confronti con `compareTo`, mai `equals`. Mai `double` per i soldi.
- Id `UUID`; `created_at` ovunque; timestamp in UTC (`Instant`), date `LocalDate`.
- Date ISO 8601 nell'API (`YYYY-MM-DD`), formato italiano solo a schermo.
- Migrazioni solo con Flyway (`V1__core.sql`); `spring.jpa.hibernate.ddl-auto=validate`. Mai modificare una migrazione già applicata.
- Soft delete (`deleted_at`, `@SoftDelete` TIMESTAMP) solo su `expenses` e `settlements`. Hard delete altrove.
- Prefisso API `/api`; errori in Problem Details (RFC 9457) con `status`, `title`, `detail`, e `errors[]` per la validazione; mai stack trace.
- L'id dell'utente si prende **sempre** dal token (`@CurrentUserId`), mai dal body o dall'URL.
- Ogni service method su `/trips/{tripId}` inizia con `tripAccess.requireMember(...)` o `requireOrganizer(...)`.
- Viaggio `CLOSED` = sola lettura: scritture su spese e rimborsi → `409`.
- Invariante quote: Σ `expense_shares.amount` = `expenses.amount`; anche `EQUAL` viene salvata come quote esplicite.
- Password: BCrypt costo 12; min 8 caratteri, almeno una lettera e una cifra; login fallito risponde sempre «Credenziali non valide».
- JWT HS256, 24 h, claim solo `sub` ed `exp`; segreto `JWT_SECRET` ≥ 32 byte da variabile d'ambiente.
- CSRF disabilitato (API stateless, token nell'header) e documentato (D-17); CORS limitato a `CORS_ORIGIN`.
- Frontend: `erasableSyntaxOnly` è attivo in `tsconfig.app.json` → niente `enum` e niente parameter properties nei costruttori; `verbatimModuleSyntax` → `import type` per i tipi.
- Niente Redux; un solo Context (`AuthContext`); dati dal server solo via TanStack Query.
- UI mobile-first: colonna singola da 360 px, tab bar in basso, azione principale come bottone flottante.

## Review Focus

Casi che la spec implica ma che nessun test copriva in prima stesura; ognuno ha ora il suo test nel task indicato.

1. **Descrizione con soli spazi** (`"   "`): deve dare `400` con `errors[0].field = "description"`, non salvare una spesa vuota → test in BE-07.
2. **Quota personalizzata con 3 decimali** (`10.005`): `400` di validazione (`@Digits`), non arrotondamento silenzioso → test in BE-07.
3. **Rimborso a sé stessi** (`fromUserId == toUserId`): `400`, non un movimento che si annulla → test in BE-08.
4. **Ripristino di una spesa cancellata dopo che un membro coinvolto ha lasciato il viaggio**: `409` con messaggio chiaro, non una spesa con quote di un non-membro → test in BE-07.
5. **Codice invito scritto in minuscolo o con spazi** (`" roma-7k2p "`): deve funzionare come `ROMA-7K2P` → test in BE-05.

- [ ] **Step 4: Migrazione `V1__core.sql`**

```sql
CREATE TABLE users (
    id            UUID PRIMARY KEY,
    email         VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    display_name  VARCHAR(40)  NOT NULL,
    created_at    TIMESTAMPTZ  NOT NULL
);

CREATE TABLE trips (
    id          UUID PRIMARY KEY,
    name        VARCHAR(80)  NOT NULL,
    destination VARCHAR(120) NOT NULL,
    start_date  DATE NOT NULL,
    end_date    DATE NOT NULL,
    currency    VARCHAR(3) NOT NULL DEFAULT 'EUR',
    invite_code VARCHAR(9) NOT NULL UNIQUE,
    status      VARCHAR(16) NOT NULL CHECK (status IN ('PLANNING', 'ONGOING', 'CLOSED')),
    owner_id    UUID NOT NULL REFERENCES users (id),
    created_at  TIMESTAMPTZ NOT NULL,
    updated_at  TIMESTAMPTZ NOT NULL,
    CONSTRAINT trips_dates CHECK (end_date >= start_date)
);

CREATE TABLE trip_members (
    id        UUID PRIMARY KEY,
    trip_id   UUID NOT NULL REFERENCES trips (id) ON DELETE CASCADE,
    user_id   UUID NOT NULL REFERENCES users (id),
    role      VARCHAR(16) NOT NULL CHECK (role IN ('ORGANIZER', 'MEMBER')),
    joined_at TIMESTAMPTZ NOT NULL,
    CONSTRAINT trip_members_unique UNIQUE (trip_id, user_id)
);

CREATE TABLE expenses (
    id          UUID PRIMARY KEY,
    trip_id     UUID NOT NULL REFERENCES trips (id) ON DELETE CASCADE,
    payer_id    UUID NOT NULL REFERENCES users (id),
    description VARCHAR(120) NOT NULL,
    amount      NUMERIC(12, 2) NOT NULL CHECK (amount > 0),
    date        DATE NOT NULL,
    category    VARCHAR(16) NOT NULL CHECK (category IN ('FOOD', 'TRANSPORT', 'LODGING', 'ACTIVITY', 'OTHER')),
    split_type  VARCHAR(16) NOT NULL CHECK (split_type IN ('EQUAL', 'CUSTOM')),
    created_by  UUID NOT NULL REFERENCES users (id),
    created_at  TIMESTAMPTZ NOT NULL,
    updated_at  TIMESTAMPTZ NOT NULL,
    deleted_at  TIMESTAMPTZ
);
CREATE INDEX idx_expenses_trip ON expenses (trip_id);

CREATE TABLE expense_shares (
    id         UUID PRIMARY KEY,
    expense_id UUID NOT NULL REFERENCES expenses (id) ON DELETE CASCADE,
    user_id    UUID NOT NULL REFERENCES users (id),
    amount     NUMERIC(12, 2) NOT NULL CHECK (amount >= 0),
    CONSTRAINT expense_shares_unique UNIQUE (expense_id, user_id)
);

CREATE TABLE settlements (
    id           UUID PRIMARY KEY,
    trip_id      UUID NOT NULL REFERENCES trips (id) ON DELETE CASCADE,
    from_user_id UUID NOT NULL REFERENCES users (id),
    to_user_id   UUID NOT NULL REFERENCES users (id),
    amount       NUMERIC(12, 2) NOT NULL CHECK (amount > 0),
    date         DATE NOT NULL,
    note         VARCHAR(200),
    created_by   UUID NOT NULL REFERENCES users (id),
    created_at   TIMESTAMPTZ NOT NULL,
    deleted_at   TIMESTAMPTZ,
    CONSTRAINT settlements_distinct_users CHECK (from_user_id <> to_user_id)
);
CREATE INDEX idx_settlements_trip ON settlements (trip_id);
```

```java
package com.splittrip.common;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpStatus;
import org.springframework.http.HttpStatusCode;
import org.springframework.http.ProblemDetail;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.context.request.WebRequest;
import org.springframework.web.servlet.mvc.method.annotation.ResponseEntityExceptionHandler;

import java.util.List;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler extends ResponseEntityExceptionHandler {

    private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);

    @ExceptionHandler(AppException.class)
    public ProblemDetail handleApp(AppException ex) {
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(ex.getStatus(), ex.getMessage());
        pd.setTitle(ex.getTitle());
        return pd;
    }

    @Override
    protected ResponseEntity<Object> handleMethodArgumentNotValid(MethodArgumentNotValidException ex,
                                                                  HttpHeaders headers,
                                                                  HttpStatusCode status,
                                                                  WebRequest request) {
        List<Map<String, String>> errors = ex.getBindingResult().getFieldErrors().stream()
                .map(fe -> Map.of("field", fe.getField(), "message", String.valueOf(fe.getDefaultMessage())))
                .toList();
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.BAD_REQUEST, "Alcuni campi non sono validi");
        pd.setTitle("Validazione fallita");
        pd.setProperty("errors", errors);
        return ResponseEntity.badRequest().body(pd);
    }

    @ExceptionHandler(Exception.class)
    public ProblemDetail handleUnexpected(Exception ex) {
        log.error("Errore non gestito", ex);
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.INTERNAL_SERVER_ERROR, "Si è verificato un errore interno");
        pd.setTitle("Errore interno");
        return pd;
    }
}
```

```java
package com.splittrip.auth;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwtDecoder;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.NimbusJwtDecoder;
import org.springframework.security.oauth2.jwt.NimbusJwtEncoder;

import javax.crypto.SecretKey;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;

@Configuration
public class JwtConfig {

    @Bean
    public SecretKey jwtKey(JwtProperties props) {
        byte[] bytes = props.secret().getBytes(StandardCharsets.UTF_8);
        if (bytes.length < 32) {
            throw new IllegalStateException("JWT_SECRET deve essere di almeno 32 byte");
        }
        return new SecretKeySpec(bytes, "HmacSHA256");
    }

    @Bean
    public JwtEncoder jwtEncoder(SecretKey jwtKey) {
        return NimbusJwtEncoder.withSecretKey(jwtKey).build();
    }

    @Bean
    public JwtDecoder jwtDecoder(SecretKey jwtKey) {
        return NimbusJwtDecoder.withSecretKey(jwtKey).macAlgorithm(MacAlgorithm.HS256).build();
    }
}
```

```java
package com.splittrip.auth;

import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwsHeader;
import org.springframework.security.oauth2.jwt.JwtClaimsSet;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtEncoderParameters;
import org.springframework.stereotype.Service;

import java.time.Clock;
import java.time.Instant;
import java.util.UUID;

@Service
public class JwtService {

    private final JwtEncoder encoder;
    private final JwtProperties props;
    private final Clock clock;

    public JwtService(JwtEncoder encoder, JwtProperties props, Clock clock) {
        this.encoder = encoder;
        this.props = props;
        this.clock = clock;
    }

    public String issue(UUID userId) {
        Instant now = clock.instant();
        JwtClaimsSet claims = JwtClaimsSet.builder()
                .subject(userId.toString())
                .issuedAt(now)
                .expiresAt(now.plus(props.ttl()))
                .build();
        JwsHeader header = JwsHeader.with(MacAlgorithm.HS256).build();
        return encoder.encode(JwtEncoderParameters.from(header, claims)).getTokenValue();
    }
}
```

```java
package com.splittrip.auth;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.HttpMethod;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.web.cors.CorsConfiguration;
import org.springframework.web.cors.CorsConfigurationSource;
import org.springframework.web.cors.UrlBasedCorsConfigurationSource;

import java.util.List;

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http, ProblemAuthHandlers handlers) throws Exception {
        http
            // API stateless con JWT nell'header Authorization: la protezione CSRF serve ai cookie
            // di sessione, che non usiamo. Vedi docs/decisioni.md D-17.
            .csrf(csrf -> csrf.disable())
            .cors(Customizer.withDefaults())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .headers(h -> h.contentSecurityPolicy(c -> c.policyDirectives(
                    "default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; frame-ancestors 'none'")))
            .authorizeHttpRequests(auth -> auth
                    .requestMatchers(HttpMethod.OPTIONS, "/**").permitAll()
                    .requestMatchers("/api/auth/**", "/actuator/health", "/swagger-ui.html",
                            "/swagger-ui/**", "/v3/api-docs/**", "/error").permitAll()
                    .anyRequest().authenticated())
            .oauth2ResourceServer(o -> o
                    .jwt(Customizer.withDefaults())
                    .authenticationEntryPoint(handlers.entryPoint())
                    .accessDeniedHandler(handlers.deniedHandler()))
            .exceptionHandling(e -> e
                    .authenticationEntryPoint(handlers.entryPoint())
                    .accessDeniedHandler(handlers.deniedHandler()));
        return http.build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(12);
    }

    @Bean
    public CorsConfigurationSource corsConfigurationSource(CorsProperties cors) {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOrigins(List.of(cors.origin()));
        config.setAllowedMethods(List.of("GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"));
        config.setAllowedHeaders(List.of("Authorization", "Content-Type"));
        config.setMaxAge(3600L);
        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/**", config);
        return source;
    }
}
```

```java
package com.splittrip.common;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.env.EnvironmentPostProcessor;
import org.springframework.core.env.ConfigurableEnvironment;
import org.springframework.core.env.MapPropertySource;

import java.net.URI;
import java.util.HashMap;
import java.util.Map;

/** Converte DATABASE_URL (formato postgresql://user:pass@host:port/db di Render) nelle proprietà Spring. */
public class DatabaseUrlEnvironmentPostProcessor implements EnvironmentPostProcessor {

    @Override
    public void postProcessEnvironment(ConfigurableEnvironment env, SpringApplication app) {
        String url = env.getProperty("DATABASE_URL");
        if (url == null || url.startsWith("jdbc:")) {
            if (url != null) {
                env.getPropertySources().addFirst(new MapPropertySource("databaseUrl", Map.of("JDBC_DATABASE_URL", url)));
            }
            return;
        }
        URI uri = URI.create(url);
        String[] userInfo = uri.getUserInfo() == null ? new String[0] : uri.getUserInfo().split(":", 2);
        int port = uri.getPort() == -1 ? 5432 : uri.getPort();
        Map<String, Object> props = new HashMap<>();
        props.put("JDBC_DATABASE_URL", "jdbc:postgresql://" + uri.getHost() + ":" + port + uri.getPath());
        if (userInfo.length == 2) {
            props.put("spring.datasource.username", userInfo[0]);
            props.put("spring.datasource.password", userInfo[1]);
        }
        env.getPropertySources().addFirst(new MapPropertySource("databaseUrl", props));
    }
}
```

```java
package com.splittrip.auth;

import com.splittrip.auth.dto.AuthResponse;
import com.splittrip.auth.dto.LoginRequest;
import com.splittrip.auth.dto.RegisterRequest;
import com.splittrip.common.ConflictException;
import com.splittrip.common.UnauthorizedException;
import com.splittrip.user.User;
import com.splittrip.user.UserRepository;
import com.splittrip.user.dto.UserResponse;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Clock;
import java.util.Locale;

@Service
public class AuthService {

    private final UserRepository users;
    private final PasswordEncoder encoder;
    private final JwtService jwt;
    private final Clock clock;

    public AuthService(UserRepository users, PasswordEncoder encoder, JwtService jwt, Clock clock) {
        this.users = users;
        this.encoder = encoder;
        this.jwt = jwt;
        this.clock = clock;
    }

    @Transactional
    public AuthResponse register(RegisterRequest req) {
        String email = normalize(req.email());
        if (users.existsByEmail(email)) {
            throw new ConflictException("Esiste già un account con questa email");
        }
        User user = users.save(new User(email, encoder.encode(req.password()), req.displayName().strip(), clock.instant()));
        return new AuthResponse(jwt.issue(user.getId()), UserResponse.from(user));
    }

    @Transactional(readOnly = true)
    public AuthResponse login(LoginRequest req) {
        User user = users.findByEmail(normalize(req.email()))
                .filter(u -> encoder.matches(req.password(), u.getPasswordHash()))
                .orElseThrow(() -> new UnauthorizedException("Credenziali non valide"));
        return new AuthResponse(jwt.issue(user.getId()), UserResponse.from(user));
    }

    static String normalize(String email) {
        return email.strip().toLowerCase(Locale.ROOT);
    }
}
```

`RateLimitFilter.java`:

```java
package com.splittrip.auth;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.time.Clock;
import java.time.Instant;
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/** Finestra scorrevole in memoria, per IP, sugli endpoint di autenticazione. */
public class RateLimitFilter extends OncePerRequestFilter {

    private final RateLimitProperties props;
    private final Clock clock;
    private final Map<String, Deque<Instant>> hits = new ConcurrentHashMap<>();

    public RateLimitFilter(RateLimitProperties props, Clock clock) {
        this.props = props;
        this.clock = clock;
    }

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        return !request.getRequestURI().startsWith("/api/auth/");
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        if (tryAcquire(request.getRemoteAddr())) {
            chain.doFilter(request, response);
            return;
        }
        response.setStatus(429);
        response.setContentType("application/problem+json");
        response.setCharacterEncoding("UTF-8");
        response.getWriter().write("{\"status\":429,\"title\":\"Troppe richieste\",\"detail\":\"Riprova tra qualche minuto\"}");
    }

    boolean tryAcquire(String key) {
        Instant now = clock.instant();
        Instant threshold = now.minus(props.window());
        Deque<Instant> deque = hits.computeIfAbsent(key, k -> new ArrayDeque<>());
        synchronized (deque) {
            while (!deque.isEmpty() && deque.peekFirst().isBefore(threshold)) {
                deque.pollFirst();
            }
            if (deque.size() >= props.maxRequests()) {
                return false;
            }
            deque.addLast(now);
            return true;
        }
    }
}
```

```java
import org.springframework.stereotype.Component;

import java.security.SecureRandom;
import java.util.Locale;

@Component
public class InviteCodeGenerator {

    private static final String ALPHABET = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789";
    private final SecureRandom random = new SecureRandom();

    public String generate() {
        StringBuilder sb = new StringBuilder(9);
        for (int i = 0; i < 8; i++) {
            if (i == 4) sb.append('-');
            sb.append(ALPHABET.charAt(random.nextInt(ALPHABET.length())));
        }
        return sb.toString();
    }

    public static String normalize(String code) {
        return code == null ? "" : code.strip().toUpperCase(Locale.ROOT);
    }
}
```

```java
package com.splittrip.trip;

import com.splittrip.common.ConflictException;
import com.splittrip.common.ForbiddenException;
import com.splittrip.common.NotFoundException;
import org.springframework.stereotype.Service;

import java.util.UUID;

@Service
public class TripAccessService {

    private final TripRepository trips;
    private final TripMemberRepository members;

    public TripAccessService(TripRepository trips, TripMemberRepository members) {
        this.trips = trips;
        this.members = members;
    }

    public TripMember requireMember(UUID tripId, UUID userId) {
        if (!trips.existsById(tripId)) {
            throw new NotFoundException("Viaggio non trovato");
        }
        return members.findByTripIdAndUserId(tripId, userId)
                .orElseThrow(() -> new ForbiddenException("Non fai parte di questo viaggio"));
    }

    public TripMember requireOrganizer(UUID tripId, UUID userId) {
        TripMember m = requireMember(tripId, userId);
        if (!m.isOrganizer()) {
            throw new ForbiddenException("Solo l'organizzatore può farlo");
        }
        return m;
    }

    public void requireWritable(Trip trip) {
        if (trip.isClosed()) {
            throw new ConflictException("Il viaggio è chiuso: non si possono fare modifiche");
        }
    }
}
```

```java
package com.splittrip.trip;

import com.splittrip.common.BadRequestException;
import com.splittrip.trip.dto.*;
import com.splittrip.user.User;
import com.splittrip.user.UserService;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Clock;
import java.time.Instant;
import java.time.LocalDate;
import java.util.List;
import java.util.UUID;

@Service
public class TripService {

    private final TripRepository trips;
    private final TripMemberRepository members;
    private final UserService users;
    private final TripAccessService access;
    private final InviteCodeGenerator codes;
    private final Clock clock;

    public TripService(TripRepository trips, TripMemberRepository members, UserService users,
                       TripAccessService access, InviteCodeGenerator codes, Clock clock) {
        this.trips = trips;
        this.members = members;
        this.users = users;
        this.access = access;
        this.codes = codes;
        this.clock = clock;
    }

    @Transactional
    public TripResponse create(UUID userId, TripRequest req) {
        validateDates(req.startDate(), req.endDate());
        User owner = users.require(userId);
        Instant now = clock.instant();
        String currency = req.currency() == null ? "EUR" : req.currency();
        Trip trip = trips.save(new Trip(req.name().strip(), req.destination().strip(), req.startDate(), req.endDate(),
                currency, uniqueCode(), owner, now));
        members.save(new TripMember(trip, owner, MemberRole.ORGANIZER, now));
        return get(trip.getId(), userId);
    }

    @Transactional(readOnly = true)
    public List<TripSummaryResponse> listForUser(UUID userId) {
        return trips.findAllByMemberUserId(userId).stream()
                .map(t -> new TripSummaryResponse(t.getId(), t.getName(), t.getDestination(), t.getStartDate(),
                        t.getEndDate(), t.getCurrency(), t.getStatus(), members.countByTripId(t.getId()),
                        members.findByTripIdAndUserId(t.getId(), userId).map(TripMember::getRole).orElse(MemberRole.MEMBER)))
                .toList();
    }

    @Transactional(readOnly = true)
    public TripResponse get(UUID tripId, UUID userId) {
        access.requireMember(tripId, userId);
        Trip trip = trips.findById(tripId).orElseThrow();
        return TripResponse.from(trip, members.findByTripIdOrderByJoinedAtAsc(tripId));
    }

    String uniqueCode() {
        String code;
        do {
            code = codes.generate();
        } while (trips.existsByInviteCode(code));
        return code;
    }

    static void validateDates(LocalDate start, LocalDate end) {
        if (end.isBefore(start)) {
            throw new BadRequestException("La data di fine deve essere uguale o successiva a quella di inizio");
        }
    }
}
```

```java
package com.splittrip.expense;

import java.math.BigDecimal;
import java.util.*;

/**
 * Calcola i saldi netti di un viaggio e li semplifica in una lista di trasferimenti.
 * Classe pura: nessuna dipendenza da Spring o dal database.
 */
public final class BalanceCalculator {

    public record ShareInput(UUID userId, BigDecimal amount) {}
    public record ExpenseInput(UUID payerId, BigDecimal amount, List<ShareInput> shares) {}
    public record SettlementInput(UUID fromUserId, UUID toUserId, BigDecimal amount) {}
    public record MemberBalance(UUID userId, BigDecimal paid, BigDecimal owed, BigDecimal net) {}
    public record Transfer(UUID fromUserId, UUID toUserId, BigDecimal amount) {}
    public record Result(List<MemberBalance> balances, List<Transfer> suggestedTransfers) {}

    public Result compute(Collection<UUID> memberIds, List<ExpenseInput> expenses, List<SettlementInput> settlements) {
        // Tutto in centesimi (long): niente arrotondamenti intermedi.
        SortedMap<UUID, long[]> acc = new TreeMap<>(); // [paid, owed, settledGiven, settledReceived]
        memberIds.forEach(id -> acc.put(id, new long[4]));

        for (ExpenseInput e : expenses) {
            acc.computeIfAbsent(e.payerId(), k -> new long[4])[0] += cents(e.amount());
            for (ShareInput s : e.shares()) {
                acc.computeIfAbsent(s.userId(), k -> new long[4])[1] += cents(s.amount());
            }
        }
        for (SettlementInput s : settlements) {
            acc.computeIfAbsent(s.fromUserId(), k -> new long[4])[2] += cents(s.amount());
            acc.computeIfAbsent(s.toUserId(), k -> new long[4])[3] += cents(s.amount());
        }

        List<MemberBalance> balances = new ArrayList<>();
        Map<UUID, Long> nets = new LinkedHashMap<>();
        acc.forEach((id, v) -> {
            long net = v[0] - v[1] + v[2] - v[3];
            nets.put(id, net);
            balances.add(new MemberBalance(id, eur(v[0]), eur(v[1]), eur(net)));
        });
        return new Result(List.copyOf(balances), simplify(nets));
    }

    /** Greedy: il debitore più grande paga il creditore più grande. Al massimo n−1 trasferimenti. */
    private static List<Transfer> simplify(Map<UUID, Long> nets) {
        Comparator<Map.Entry<UUID, Long>> byAbsDescThenId = Comparator
                .<Map.Entry<UUID, Long>>comparingLong(e -> -Math.abs(e.getValue()))
                .thenComparing(Map.Entry::getKey);
        List<Map.Entry<UUID, Long>> creditors = nets.entrySet().stream().filter(e -> e.getValue() > 0)
                .map(e -> Map.entry(e.getKey(), e.getValue())).sorted(byAbsDescThenId).toList();
        List<Map.Entry<UUID, Long>> debtors = nets.entrySet().stream().filter(e -> e.getValue() < 0)
                .map(e -> Map.entry(e.getKey(), -e.getValue())).sorted(byAbsDescThenId).toList();

        long[] credit = creditors.stream().mapToLong(Map.Entry::getValue).toArray();
        long[] debt = debtors.stream().mapToLong(Map.Entry::getValue).toArray();
        List<Transfer> transfers = new ArrayList<>();
        int c = 0, d = 0;
        while (c < credit.length && d < debt.length) {
            long amount = Math.min(credit[c], debt[d]);
            transfers.add(new Transfer(debtors.get(d).getKey(), creditors.get(c).getKey(), eur(amount)));
            credit[c] -= amount;
            debt[d] -= amount;
            if (credit[c] == 0) c++;
            if (debt[d] == 0) d++;
        }
        return List.copyOf(transfers);
    }

    static long cents(BigDecimal amount) {
        return amount.setScale(2, java.math.RoundingMode.HALF_UP).movePointRight(2).longValueExact();
    }

    static BigDecimal eur(long cents) {
        return BigDecimal.valueOf(cents, 2);
    }
}
```

```java
package com.splittrip.expense;

import com.splittrip.expense.BalanceCalculator.ShareInput;

import java.math.BigDecimal;
import java.util.ArrayList;
import java.util.Collection;
import java.util.List;
import java.util.UUID;

/** Divide un importo in parti uguali; i centesimi di resto vanno ai primi membri in ordine di id. */
public final class EqualSplitter {

    private EqualSplitter() {}

    public static List<ShareInput> split(BigDecimal total, Collection<UUID> userIds) {
        List<UUID> sorted = userIds.stream().distinct().sorted().toList();
        if (sorted.isEmpty()) {
            throw new IllegalArgumentException("Serve almeno un partecipante");
        }
        long cents = BalanceCalculator.cents(total);
        long base = cents / sorted.size();
        long remainder = cents % sorted.size();
        List<ShareInput> shares = new ArrayList<>(sorted.size());
        for (int i = 0; i < sorted.size(); i++) {
            shares.add(new ShareInput(sorted.get(i), BalanceCalculator.eur(base + (i < remainder ? 1 : 0))));
        }
        return shares;
    }
}
```

```java
package com.splittrip.expense;

import com.splittrip.common.BadRequestException;
import com.splittrip.common.ConflictException;

import com.splittrip.common.NotFoundException;
import com.splittrip.expense.BalanceCalculator.ShareInput;

import com.splittrip.trip.TripAccessService;
import com.splittrip.trip.TripMember;
import com.splittrip.trip.TripMemberRepository;
import com.splittrip.trip.TripRepository;
import com.splittrip.user.User;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.math.BigDecimal;
import java.time.Clock;
import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;

@Service
public class ExpenseService {

    private final ExpenseRepository expenses;
    private final ExpenseShareRepository shares;
    private final ExpenseTrashRepository trash;
    private final TripRepository trips;
    private final TripMemberRepository members;
    private final TripAccessService access;
    private final UserRepository users;
    private final Clock clock;

    public ExpenseService(ExpenseRepository expenses, ExpenseShareRepository shares, ExpenseTrashRepository trash,
                          TripRepository trips, TripMemberRepository members, TripAccessService access,
                          UserRepository users, Clock clock) {
        this.expenses = expenses;
        this.shares = shares;
        this.trash = trash;
        this.trips = trips;
        this.members = members;
        this.access = access;
        this.users = users;
        this.clock = clock;
    }

    @Transactional(readOnly = true)
    public List<ExpenseResponse> list(UUID tripId, UUID userId, ExpenseCategory category) {
        access.requireMember(tripId, userId);
        return expenses.findAllByTripIdWithShares(tripId).stream()
                .filter(e -> category == null || e.getCategory() == category)
                .map(ExpenseResponse::from)
                .toList();
    }

    @Transactional(readOnly = true)
    public ExpenseResponse get(UUID tripId, UUID userId, UUID expenseId) {
        access.requireMember(tripId, userId);
        return ExpenseResponse.from(require(tripId, expenseId));
    }

    @Transactional
    public ExpenseResponse create(UUID tripId, UUID userId, ExpenseRequest req) {
        TripMember me = access.requireMember(tripId, userId);
        Trip trip = trips.findById(tripId).orElseThrow();
        access.requireWritable(trip);
        Map<UUID, User> memberUsers = memberUsers(tripId);
        List<ShareInput> computed = computeShares(req, memberUsers);

        Expense expense = new Expense(trip, memberUsers.get(req.payerId()), req.description().strip(), req.amount(),
                req.date(), req.category(), req.splitType(), me.getUser(), clock.instant());
        for (ShareInput s : computed) {
            expense.getShares().add(new ExpenseShare(expense, memberUsers.get(s.userId()), s.amount()));
        }
        expenses.save(expense);
        return get(tripId, userId, expense.getId());
    }

    @Transactional
    public ExpenseResponse update(UUID tripId, UUID userId, UUID expenseId, ExpenseRequest req) {
        TripMember me = access.requireMember(tripId, userId);
        Trip trip = trips.findById(tripId).orElseThrow();
        access.requireWritable(trip);
        Expense expense = require(tripId, expenseId);
        requireOwnerOrOrganizer(expense, me);
        Map<UUID, User> memberUsers = memberUsers(tripId);
        List<ShareInput> computed = computeShares(req, memberUsers);

        expense.setPayer(memberUsers.get(req.payerId()));
        expense.setDescription(req.description().strip());
        expense.setAmount(req.amount());
        expense.setDate(req.date());
        expense.setCategory(req.category());
        expense.setSplitType(req.splitType());
        expense.setUpdatedAt(clock.instant());
        shares.deleteAllByExpenseId(expenseId);
        shares.flush();
        expense.getShares().clear();
        for (ShareInput s : computed) {
            expense.getShares().add(new ExpenseShare(expense, memberUsers.get(s.userId()), s.amount()));
        }
        expenses.saveAndFlush(expense);
        return get(tripId, userId, expenseId);
    }

    @Transactional
    public void delete(UUID tripId, UUID userId, UUID expenseId) {
        TripMember me = access.requireMember(tripId, userId);
        access.requireWritable(trips.findById(tripId).orElseThrow());
        Expense expense = require(tripId, expenseId);
        requireOwnerOrOrganizer(expense, me);
        expenses.delete(expense); // soft delete: UPDATE expenses SET deleted_at = now()
    }

    @Transactional(readOnly = true)
    public List<TrashedExpenseResponse> trash(UUID tripId, UUID userId) {
        access.requireOrganizer(tripId, userId);
        return trash.findTrashed(tripId);
    }

    @Transactional
    public ExpenseResponse restore(UUID tripId, UUID userId, UUID expenseId) {
        access.requireOrganizer(tripId, userId);
        access.requireWritable(trips.findById(tripId).orElseThrow());
        if (!trash.isTrashed(tripId, expenseId)) {
            throw new NotFoundException("Spesa non trovata nel cestino");
        }
        Map<UUID, User> memberUsers = memberUsers(tripId);
        for (UUID shareUser : trash.shareUserIds(expenseId)) {
            if (!memberUsers.containsKey(shareUser)) {
                String name = users.findById(shareUser).map(User::getDisplayName).orElse("un ex membro");
                throw new ConflictException("Non si può ripristinare: " + name + " non fa più parte del viaggio");
            }
        }
        trash.restore(tripId, expenseId);
        return get(tripId, userId, expenseId);
    }

    private Expense require(UUID tripId, UUID expenseId) {
        return expenses.findByIdAndTripIdWithShares(expenseId, tripId)
                .orElseThrow(() -> new NotFoundException("Spesa non trovata"));
    }

    private static void requireOwnerOrOrganizer(Expense expense, TripMember me) {
        boolean owner = expense.getCreatedBy().getId().equals(me.getUser().getId());
        if (!owner && !me.isOrganizer()) {
            throw new ForbiddenException("Solo chi ha creato la spesa o l'organizzatore può modificarla");
        }
    }

    private Map<UUID, User> memberUsers(UUID tripId) {
        return members.findByTripIdOrderByJoinedAtAsc(tripId).stream()
                .map(TripMember::getUser)
                .collect(Collectors.toMap(User::getId, Function.identity(), (a, b) -> a, LinkedHashMap::new));
    }

    /** Valida pagante e partecipanti e produce le quote da salvare (anche per EQUAL). */
    static List<ShareInput> computeShares(ExpenseRequest req, Map<UUID, User> memberUsers) {
        if (!memberUsers.containsKey(req.payerId())) {
            throw new BadRequestException("Chi ha pagato deve far parte del viaggio");
        }
        List<UUID> userIds = req.shares().stream().map(ShareRequest::userId).toList();
        if (new HashSet<>(userIds).size() != userIds.size()) {
            throw new BadRequestException("Un partecipante compare più di una volta");
        }
        for (UUID id : userIds) {
            if (!memberUsers.containsKey(id)) {
                throw new BadRequestException("Tutti i partecipanti alla spesa devono far parte del viaggio");
            }
        }
        if (req.splitType() == SplitType.EQUAL) {
            return EqualSplitter.split(req.amount(), userIds);
        }
        BigDecimal sum = BigDecimal.ZERO;
        List<ShareInput> result = new ArrayList<>();
        for (ShareRequest s : req.shares()) {
            if (s.amount() == null) {
                throw new BadRequestException("Con la divisione personalizzata ogni quota deve avere un importo");
            }
            sum = sum.add(s.amount());
            result.add(new ShareInput(s.userId(), s.amount().setScale(2)));
        }
        if (sum.compareTo(req.amount()) != 0) {
            throw new BadRequestException("La somma delle quote (" + sum.setScale(2) + ") non corrisponde al totale ("
                    + req.amount().setScale(2) + ")");
        }
        return result;
    }
}
```

```java
import java.time.Clock;
import java.util.List;
import java.util.UUID;

@Service
public class SettlementService {

    private final SettlementRepository settlements;
    private final TripRepository trips;
    private final TripMemberRepository members;
    private final TripAccessService access;
    private final Clock clock;

    public SettlementService(SettlementRepository settlements, TripRepository trips, TripMemberRepository members,
                             TripAccessService access, Clock clock) {
        this.settlements = settlements;
        this.trips = trips;
        this.members = members;
        this.access = access;
        this.clock = clock;
    }

    @Transactional(readOnly = true)
    public List<SettlementResponse> list(UUID tripId, UUID userId) {
        access.requireMember(tripId, userId);
        return settlements.findAllByTripIdWithUsers(tripId).stream().map(SettlementResponse::from).toList();
    }

    @Transactional
    public SettlementResponse create(UUID tripId, UUID userId, SettlementRequest req) {
        TripMember me = access.requireMember(tripId, userId);
        Trip trip = trips.findById(tripId).orElseThrow();
        access.requireWritable(trip);
        if (req.fromUserId().equals(req.toUserId())) {
            throw new BadRequestException("Chi restituisce e chi riceve devono essere persone diverse");
        }
        TripMember from = members.findByTripIdAndUserId(tripId, req.fromUserId())
                .orElseThrow(() -> new BadRequestException("Chi restituisce deve far parte del viaggio"));
        TripMember to = members.findByTripIdAndUserId(tripId, req.toUserId())
                .orElseThrow(() -> new BadRequestException("Chi riceve deve far parte del viaggio"));
        String note = req.note() == null || req.note().isBlank() ? null : req.note().strip();
        Settlement s = settlements.save(new Settlement(trip, from.getUser(), to.getUser(), req.amount(), req.date(),
                note, me.getUser(), clock.instant()));
        return SettlementResponse.from(settlements.findByIdAndTripId(s.getId(), tripId).orElseThrow());
    }

    @Transactional
    public void delete(UUID tripId, UUID userId, UUID settlementId) {
        TripMember me = access.requireMember(tripId, userId);
        access.requireWritable(trips.findById(tripId).orElseThrow());
        Settlement s = settlements.findByIdAndTripId(settlementId, tripId)
                .orElseThrow(() -> new NotFoundException("Rimborso non trovato"));
        if (!s.getCreatedBy().getId().equals(userId) && !me.isOrganizer()) {
            throw new ForbiddenException("Solo chi ha registrato il rimborso o l'organizzatore può cancellarlo");
        }
        settlements.delete(s);
    }
}
```

```java
package com.splittrip.expense;

import com.splittrip.expense.BalanceCalculator.*;
import com.splittrip.expense.dto.*;
import com.splittrip.trip.TripAccessService;
import com.splittrip.trip.TripMember;
import com.splittrip.trip.TripMemberRepository;
import com.splittrip.user.User;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.math.BigDecimal;
import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;

@Service
public class BalanceService {

    private final ExpenseRepository expenses;
    private final SettlementRepository settlements;
    private final TripMemberRepository members;
    private final TripAccessService access;
    private final BalanceCalculator calculator = new BalanceCalculator();

    public BalanceService(ExpenseRepository expenses, SettlementRepository settlements,
                          TripMemberRepository members, TripAccessService access) {
        this.expenses = expenses;
        this.settlements = settlements;
        this.members = members;
        this.access = access;
    }

    @Transactional(readOnly = true)
    public BalancesResponse balances(UUID tripId, UUID userId) {
        access.requireMember(tripId, userId);
        Map<UUID, String> names = names(tripId);
        List<ExpenseInput> expenseInputs = expenses.findAllByTripIdWithShares(tripId).stream()
                .map(e -> new ExpenseInput(e.getPayer().getId(), e.getAmount(),
                        e.getShares().stream().map(s -> new ShareInput(s.getUser().getId(), s.getAmount())).toList()))
                .toList();
        List<SettlementInput> settlementInputs = settlements.findAllByTripIdWithUsers(tripId).stream()
                .map(s -> new SettlementInput(s.getFromUser().getId(), s.getToUser().getId(), s.getAmount()))
                .toList();

        Result result = calculator.compute(names.keySet(), expenseInputs, settlementInputs);
        return new BalancesResponse(
                result.balances().stream()
                        .map(b -> new MemberBalanceResponse(b.userId(), names.getOrDefault(b.userId(), "ex membro"), b.paid(), b.owed(), b.net()))
                        .toList(),
                result.suggestedTransfers().stream()
                        .map(t -> new TransferResponse(t.fromUserId(), names.getOrDefault(t.fromUserId(), "ex membro"),
                                t.toUserId(), names.getOrDefault(t.toUserId(), "ex membro"), t.amount()))
                        .toList());
    }

    @Transactional(readOnly = true)
    public SummaryResponse summary(UUID tripId, UUID userId) {
        access.requireMember(tripId, userId);
        List<Expense> all = expenses.findAllByTripIdWithShares(tripId);
        BigDecimal total = all.stream().map(Expense::getAmount).reduce(BigDecimal.ZERO, BigDecimal::add).setScale(2);
        Map<String, BigDecimal> byCategory = new TreeMap<>();
        for (Expense e : all) {
            byCategory.merge(e.getCategory().name(), e.getAmount(), BigDecimal::add);
        }
        Map<UUID, BigDecimal> payerTotals = new LinkedHashMap<>();
        Map<UUID, String> names = names(tripId);
        for (Expense e : all) {
            payerTotals.merge(e.getPayer().getId(), e.getAmount(), BigDecimal::add);
        }
        List<SummaryResponse.PayerTotal> byPayer = payerTotals.entrySet().stream()
                .sorted(Map.Entry.<UUID, BigDecimal>comparingByValue().reversed())
                .map(en -> new SummaryResponse.PayerTotal(en.getKey(), names.getOrDefault(en.getKey(), "ex membro"), en.getValue()))
                .toList();
        return new SummaryResponse(total, byCategory, byPayer);
    }

    private Map<UUID, String> names(UUID tripId) {
        return members.findByTripIdOrderByJoinedAtAsc(tripId).stream()
                .map(TripMember::getUser)
                .collect(Collectors.toMap(User::getId, User::getDisplayName, (a, b) -> a, LinkedHashMap::new));
    }
}
```

```ts
export type FieldError = { field: string; message: string }

export class ApiError extends Error {
  status: number
  title: string
  detail: string
  errors: FieldError[]

  constructor(status: number, title: string, detail: string, errors: FieldError[] = []) {
    super(detail)
    this.name = 'ApiError'
    this.status = status
    this.title = title
    this.detail = detail
    this.errors = errors
  }
}

const BASE: string = import.meta.env.VITE_API_URL ?? '/api'

let getToken: () => string | null = () => null
let onUnauthorized: () => void = () => {}

export function configureClient(opts: { getToken: () => string | null; onUnauthorized: () => void }) {
  getToken = opts.getToken
  onUnauthorized = opts.onUnauthorized
}

type Options = { method?: 'GET' | 'POST' | 'PUT' | 'PATCH' | 'DELETE'; body?: unknown; signal?: AbortSignal }

export async function api<T>(path: string, options: Options = {}): Promise<T> {
  const headers: Record<string, string> = {}
  if (options.body !== undefined) headers['Content-Type'] = 'application/json'
  const token = getToken()
  if (token) headers.Authorization = `Bearer ${token}`

  const res = await fetch(BASE + path, {
    method: options.method ?? 'GET',
    headers,
    body: options.body === undefined ? undefined : JSON.stringify(options.body),
    signal: options.signal,
  })

  if (res.status === 204) return undefined as T
  const text = await res.text()
  const data = text ? JSON.parse(text) : null

  if (!res.ok) {
    if (res.status === 401 && !path.startsWith('/auth/')) onUnauthorized()
    throw new ApiError(res.status, data?.title ?? 'Errore', data?.detail ?? `Errore ${res.status}`, data?.errors ?? [])
  }
  return data as T
}
```

```ts
export function formatDateRange(startIso: string, endIso: string): string {
  const start = parseISO(startIso)
  const end = parseISO(endIso)
```

```tsx
import { useCallback, useEffect, useMemo, useRef, useState, type ReactNode } from 'react'
import { configureClient } from '../../shared/api/client'
import { AUTH_STORAGE_KEY, AuthContext, type AuthState } from './authContext'

function read(): AuthState | null {
  try {
    const raw = localStorage.getItem(AUTH_STORAGE_KEY)
    return raw ? (JSON.parse(raw) as AuthState) : null
  } catch {
    return null
  }
}

export function AuthProvider({ children }: { children: ReactNode }) {
  const [auth, setAuth] = useState<AuthState | null>(read)
  const authRef = useRef(auth)
  authRef.current = auth

  const login = useCallback((state: AuthState) => {
    localStorage.setItem(AUTH_STORAGE_KEY, JSON.stringify(state))
    setAuth(state)
  }, [])

  const logout = useCallback(() => {
    localStorage.removeItem(AUTH_STORAGE_KEY)
    setAuth(null)
  }, [])

  useEffect(() => {
    configureClient({ getToken: () => authRef.current?.token ?? null, onUnauthorized: logout })
  }, [logout])

  const value = useMemo(() => ({ auth, login, logout }), [auth, login, logout])
  return <AuthContext value={value}>{children}</AuthContext>
}
```

```ts
import { api } from '../../shared/api/client'
import type { JoinPreview, Trip, TripStatus, TripSummary } from '../../shared/api/types'

export type TripInput = { name: string; destination: string; startDate: string; endDate: string; currency?: string }
export type TripPatch = Partial<Omit<TripInput, 'currency'>> & { status?: TripStatus }

export const tripsApi = {
  list: () => api<TripSummary[]>('/trips'),
  get: (tripId: string) => api<Trip>(`/trips/${tripId}`),
  create: (body: TripInput) => api<Trip>('/trips', { method: 'POST', body }),
  update: (tripId: string, body: TripPatch) => api<Trip>(`/trips/${tripId}`, { method: 'PATCH', body }),
  remove: (tripId: string) => api<void>(`/trips/${tripId}`, { method: 'DELETE' }),
  joinPreview: (code: string) => api<JoinPreview>(`/trips/join-preview?code=${encodeURIComponent(code)}`),
  join: (code: string) => api<Trip>('/trips/join', { method: 'POST', body: { code } }),
  regenerateCode: (tripId: string) => api<Trip>(`/trips/${tripId}/invite-code/regenerate`, { method: 'POST' }),
  removeMember: (tripId: string, userId: string) => api<void>(`/trips/${tripId}/members/${userId}`, { method: 'DELETE' }),
}
```

`src/features/trips/useTrips.ts`:

```ts
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query'
import { tripsApi, type TripInput, type TripPatch } from './tripsApi'

export const tripKeys = {
  all: ['trips'] as const,
  one: (tripId: string) => ['trips', tripId] as const,
}

export function useTrips() {
  return useQuery({ queryKey: tripKeys.all, queryFn: tripsApi.list })
}

export function useTrip(tripId: string) {
  return useQuery({ queryKey: tripKeys.one(tripId), queryFn: () => tripsApi.get(tripId) })
}

export function useCreateTrip() {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: (body: TripInput) => tripsApi.create(body),
    onSuccess: () => qc.invalidateQueries({ queryKey: tripKeys.all }),
  })
}

export function useJoinTrip() {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: (code: string) => tripsApi.join(code),
    onSuccess: () => qc.invalidateQueries({ queryKey: tripKeys.all }),
  })
}

export function useUpdateTrip(tripId: string) {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: (body: TripPatch) => tripsApi.update(tripId, body),
    onSuccess: () => qc.invalidateQueries({ queryKey: tripKeys.all }),
  })
}

export function useDeleteTrip() {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: (tripId: string) => tripsApi.remove(tripId),
    onSuccess: () => qc.invalidateQueries({ queryKey: tripKeys.all }),
  })
}

export function useRegenerateCode(tripId: string) {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: () => tripsApi.regenerateCode(tripId),
    onSuccess: () => qc.invalidateQueries({ queryKey: tripKeys.one(tripId) }),
  })
}

export function useRemoveMember(tripId: string) {
  const qc = useQueryClient()
  return useMutation({
    mutationFn: (userId: string) => tripsApi.removeMember(tripId, userId),
    onSuccess: () => qc.invalidateQueries({ queryKey: tripKeys.all }),
  })
}
```

```tsx
import { useQuery } from '@tanstack/react-query'

import { Field } from '../../shared/ui/Field'

export function JoinPage() {

      <h1>Entra in un viaggio</h1>

        <div className="card">
          <h2>{preview.data.name}</h2>

          <p>{formatDateRange(preview.data.startDate, preview.data.endDate)}</p>
```

```ts
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query'
import type { ExpenseCategory, ExpenseInput } from '../../shared/api/types'
import { expensesApi } from './expensesApi'

export const expenseKeys = {
  list: (tripId: string, category?: ExpenseCategory) => ['trips', tripId, 'expenses', category ?? 'all'] as const,
  one: (tripId: string, expenseId: string) => ['trips', tripId, 'expenses', 'one', expenseId] as const,
  trash: (tripId: string) => ['trips', tripId, 'trash'] as const,
}

/** Dopo ogni scrittura si invalida tutto il viaggio: spese, cestino, saldi e riepilogo. */
function useInvalidateTrip(tripId: string) {
  const qc = useQueryClient()
  return () => qc.invalidateQueries({ queryKey: ['trips', tripId] })
}

export function useExpenses(tripId: string, category?: ExpenseCategory) {
  return useQuery({ queryKey: expenseKeys.list(tripId, category), queryFn: () => expensesApi.list(tripId, category) })
}

export function useExpense(tripId: string, expenseId: string) {
  return useQuery({ queryKey: expenseKeys.one(tripId, expenseId), queryFn: () => expensesApi.get(tripId, expenseId) })
}

export function useCreateExpense(tripId: string) {
  const invalidate = useInvalidateTrip(tripId)
  return useMutation({ mutationFn: (body: ExpenseInput) => expensesApi.create(tripId, body), onSuccess: invalidate })
}

export function useUpdateExpense(tripId: string, expenseId: string) {
  const invalidate = useInvalidateTrip(tripId)
  return useMutation({ mutationFn: (body: ExpenseInput) => expensesApi.update(tripId, expenseId, body), onSuccess: invalidate })
}

export function useDeleteExpense(tripId: string) {
  const invalidate = useInvalidateTrip(tripId)
  return useMutation({ mutationFn: (expenseId: string) => expensesApi.remove(tripId, expenseId), onSuccess: invalidate })
}

export function useTrash(tripId: string) {
  return useQuery({ queryKey: expenseKeys.trash(tripId), queryFn: () => expensesApi.trash(tripId) })
}

export function useRestoreExpense(tripId: string) {
```

```ts
import { z } from 'zod'
import type { ExpenseInput } from '../../shared/api/types'
import { formatMoney } from '../../shared/utils/format'

/** "12,50" o "12.50" → 1250 centesimi; null se non è un importo valido. */
export function parseCents(raw: string | undefined): number | null {
  if (raw === undefined) return null
  const normalized = raw.trim().replace(',', '.')
  if (!/^\d+(\.\d{1,2})?$/.test(normalized)) return null
  return Math.round(Number(normalized) * 100)
}

const shareSchema = z.object({
  userId: z.string(),
  included: z.boolean(),
  amount: z.string().optional(),
})

export const expenseSchema = z
  .object({
    description: z.string().trim().min(1, 'Scrivi cosa avete pagato').max(120, 'Al massimo 120 caratteri'),
    amount: z.string().refine((v) => (parseCents(v) ?? 0) > 0, 'Inserisci un importo maggiore di zero'),
    date: z.string().min(1, 'Scegli una data'),
    category: z.enum(['FOOD', 'TRANSPORT', 'LODGING', 'ACTIVITY', 'OTHER']),
    payerId: z.string().min(1, 'Chi ha pagato?'),
    splitType: z.enum(['EQUAL', 'CUSTOM']),
    shares: z.array(shareSchema),
  })
  .superRefine((v, ctx) => {
    const included = v.shares.filter((s) => s.included)
    if (included.length === 0) {
      ctx.addIssue({ code: 'custom', path: ['shares'], message: 'Seleziona almeno un partecipante' })
      return
    }
    if (v.splitType === 'CUSTOM') {
      let sum = 0
      for (const [i, s] of v.shares.entries()) {
        if (!s.included) continue
        const cents = parseCents(s.amount ?? '')
        if (cents === null) {
          ctx.addIssue({ code: 'custom', path: ['shares', i, 'amount'], message: 'Importo non valido' })
          return
        }
        sum += cents
      }
      const total = parseCents(v.amount) ?? 0
      if (sum !== total) {
        const diff = (total - sum) / 100
        ctx.addIssue({ code: 'custom', path: ['shares'], message: `Le quote non tornano: ${diff > 0 ? 'mancano' : 'avanzano'} ${formatMoney(Math.abs(diff))}` })
      }
    }
  })

export type ExpenseForm = z.infer<typeof expenseSchema>

export function toExpenseInput(form: ExpenseForm): ExpenseInput {
  const included = form.shares.filter((s) => s.included)
  return {
    description: form.description,
    amount: (parseCents(form.amount) ?? 0) / 100,
    date: form.date,
    category: form.category,
    payerId: form.payerId,
    splitType: form.splitType,
    shares: included.map((s) => (form.splitType === 'CUSTOM' ? { userId: s.userId, amount: (parseCents(s.amount) ?? 0) / 100 } : { userId: s.userId })),
  }
}
```

```tsx
import { expenseSchema, parseCents, toExpenseInput, type ExpenseForm } from './expenseSchema'
import { useCreateExpense, useDeleteExpense, useExpense, useUpdateExpense } from './useExpenses'

function today() {
  return new Date().toISOString().slice(0, 10)
}

export function ExpenseFormPage() {
  const { expenseId } = useParams<{ expenseId?: string }>()
  const ctx = useOutletContext<TripContext>()
  const existing = useExpense(ctx.trip.id, expenseId ?? '')
  if (expenseId && existing.isPending) return <Spinner />
  if (expenseId && !existing.data) return <FormError error={existing.error ?? new Error('Spesa non trovata')} />
  return <ExpenseFormInner ctx={ctx} expense={existing.data} />
}

function ExpenseFormInner({ ctx, expense }: { ctx: TripContext; expense?: Expense }) {
  const { trip, me, isOrganizer, canWrite } = ctx
  const navigate = useNavigate()
  const create = useCreateExpense(trip.id)
  const update = useUpdateExpense(trip.id, expense?.id ?? '')
  const remove = useDeleteExpense(trip.id)
  const [confirmDelete, setConfirmDelete] = useState(false)
  const canEdit = canWrite && (!expense || expense.createdBy === me.userId || isOrganizer)

  const { register, handleSubmit, watch, formState: { errors } } = useForm<ExpenseForm>({
    resolver: zodResolver(expenseSchema),
    defaultValues: expense
      ? {
          description: expense.description, amount: expense.amount.toFixed(2).replace('.', ','), date: expense.date,
          category: expense.category, payerId: expense.payerId, splitType: expense.splitType,
          shares: trip.members.map((m) => {
            const s = expense.shares.find((x) => x.userId === m.userId)
            return { userId: m.userId, included: !!s, amount: s ? s.amount.toFixed(2).replace('.', ',') : '' }
          }),
        }
      : {
          description: '', amount: '', date: today(), category: 'FOOD', payerId: me.userId, splitType: 'EQUAL',
          shares: trip.members.map((m) => ({ userId: m.userId, included: true, amount: '' })),
        },
  })

  const splitType = watch('splitType')
  const shares = watch('shares')
  const amount = watch('amount')
  const assigned = shares.filter((s) => s.included).reduce((sum, s) => sum + (parseCents(s.amount) ?? 0), 0)
  const remaining = ((parseCents(amount) ?? 0) - assigned) / 100

  const mutation = expense ? update : create
  const onSubmit = handleSubmit((values) =>
    mutation.mutate(toExpenseInput(values), { onSuccess: () => navigate(`/trips/${trip.id}/expenses`) }),
  )

  return (
    <form noValidate onSubmit={onSubmit} className="expense-form">
      <h2>{expense ? 'Modifica spesa' : 'Nuova spesa'}</h2>
      <Field label="Importo" inputMode="decimal" placeholder="0,00" className="amount-input" error={errors.amount?.message} {...register('amount')} />
      <Field label="Descrizione" placeholder="Es. Cena in trattoria" error={errors.description?.message} {...register('description')} />
      <div className="field">
        <label htmlFor="category">Categoria</label>
        <select id="category" {...register('category')}>
          {(Object.keys(CATEGORY_LABELS) as ExpenseCategory[]).map((c) => <option key={c} value={c}>{CATEGORY_LABELS[c]}</option>)}
        </select>
      </div>
      <Field label="Data" type="date" error={errors.date?.message} {...register('date')} />
      <div className="field">
        <label htmlFor="payerId">Chi ha pagato</label>
        <select id="payerId" {...register('payerId')}>
          {trip.members.map((m) => <option key={m.userId} value={m.userId}>{m.displayName}{m.userId === me.userId ? ' (io)' : ''}</option>)}
        </select>
      </div>

      <fieldset className="field">
        <legend>Diviso tra</legend>
        <div className="chips">
          <label className="chip"><input type="radio" value="EQUAL" {...register('splitType')} /> Parti uguali</label>
          <label className="chip"><input type="radio" value="CUSTOM" {...register('splitType')} /> Importi personalizzati</label>
        </div>
        {trip.members.map((m, i) => (
          <div key={m.userId} className="row">
            <label>
              <input type="checkbox" {...register(`shares.${i}.included`)} /> {m.displayName}
            </label>
            {splitType === 'CUSTOM' && shares[i]?.included && (
              <input aria-label={`Quota di ${m.displayName}`} inputMode="decimal" placeholder="0,00" className="share-input" {...register(`shares.${i}.amount`)} />
            )}
          </div>
        ))}
        {splitType === 'CUSTOM' && <p className={remaining === 0 ? 'muted' : 'field-error'}>Resta da assegnare: {remaining.toFixed(2).replace('.', ',')} €</p>}
        {errors.shares?.message && <p className="field-error">{errors.shares.message}</p>}
        {errors.shares?.root?.message && <p className="field-error">{errors.shares.root.message}</p>}
      </fieldset>

      <FormError error={mutation.error} />
      {canEdit ? (
        <div className="modal-actions">
          {expense && <Button type="button" variant="danger" onClick={() => setConfirmDelete(true)}>Elimina</Button>}
          <Button type="submit" loading={mutation.isPending}>Salva</Button>
        </div>
      ) : (
        <p className="muted">Puoi solo consultare questa spesa.</p>
      )}

      <Modal open={confirmDelete} title="Eliminare la spesa?" onClose={() => setConfirmDelete(false)}>

        <div className="modal-actions">

            Elimina
          </Button>
        </div>
      </Modal>
    </form>
  )
}
```

```ts
import { z } from 'zod'

export const settlementSchema = z
  .object({
    fromUserId: z.string().min(1, 'Chi restituisce?'),
    toUserId: z.string().min(1, 'Chi riceve?'),

    date: z.string().min(1, 'Scegli una data'),
    note: z.string().max(200, 'Al massimo 200 caratteri').optional(),
  })
  .refine((v) => v.fromUserId !== v.toUserId, { message: 'Devono essere due persone diverse', path: ['toUserId'] })

export type SettlementForm = z.infer<typeof settlementSchema>
```

```tsx
export function WakingBanner() {
```
