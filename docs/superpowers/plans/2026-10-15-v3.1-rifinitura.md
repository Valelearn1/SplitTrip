# v3.1 «Rifinitura» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ricerca luoghi per destinazione e foto, benvenuto all'ingresso nel viaggio, Impostazioni a tre schede, pagina di presentazione e Home ricca, profilo completo con preferenze sull'account, reazioni ed emoji in chat; pubblicati su Render con tag `v3.1`.

**Architecture:** il backend aggiunge il package `places` (Photon dietro un'interfaccia, con cache e limiti), il package `home` (un endpoint che compone la Home), le reazioni nel package `chat` (REST + `message.reacted` sul canale) e profilo/preferenze/statistiche nel package `user`. Il frontend aggiunge il componente `PlaceInput`, le pagine Benvenuto, Presentazione e Home, le Impostazioni a schede e, in chat, reazioni e griglia emoji. Niente librerie nuove.

**Tech Stack:** Spring Boot 4.1 / Java 25 / PostgreSQL / Flyway (V7); React 19, TanStack Query, react-hook-form + zod, Motion; Vitest + Testing Library + MSW; Photon (`photon.komoot.io`) via `RestClient`.

**Spec:** `docs/superpowers/specs/2026-10-15-v3.1-rifinitura-design.md`

## Global Constraints

- Soldi: `BigDecimal` scala 2 HALF_UP, mai `double`. Date ISO nell'API, italiane a schermo.
- Schema solo via Flyway (`V7__rifinitura.sql`); `ddl-auto=validate`; mai toccare V1–V6.
- Id utente sempre dal token (`@CurrentUserId`). Ogni service su un viaggio inizia con `TripAccessService.requireMember/requireOrganizer`; le scritture su un viaggio passano da `requireWritable`.
- Errori sempre in Problem Details; mai stack trace al client. Errori di campo con `FieldException(field, message)`.
- Si scrive via REST, il WebSocket spinge solo dopo il commit (`AfterCommit.run` + `LivePublisher.toTrip`).
- Luoghi (D-46): Photon solo dal backend; `q` 3–100 caratteri dopo `strip`; 30 ricerche/min per utente → 429; servizio giù → lista vuota; cache in memoria; `User-Agent: SplitTrip`; a Photon va solo il testo cercato.
- Reazioni (D-47): solo 👍 ❤️ 😂 😮 😢 🎉; una per emoji per persona; solo messaggi TEXT non eliminati; non contano nei non letti, nessuna notifica.
- Preferenze (D-48) sull'account; Home (D-49) da un solo endpoint; Impostazioni a tre schede e benvenuto senza flag (D-50).
- Accessibilità (D-24): combobox e tablist secondo gli schemi ARIA, mai solo il colore, target 44 px, focus visibile, animazioni spente con movimento ridotto (di sistema o da preferenza).
- Copy in italiano; icone Material Symbols; le emoji solo nei messaggi, nelle reazioni e nella griglia.

```java
package com.splittrip.places;

import com.splittrip.places.dto.Place;
import org.springframework.web.client.RestClient;
import org.springframework.web.util.UriComponentsBuilder;

import java.math.BigDecimal;
import java.net.URI;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;

/** Photon (OpenStreetMap). Riceve solo il testo cercato; si presenta con uno User-Agent come chiede la policy del servizio. */
public class PhotonPlaceClient implements PlaceSearchClient {

    record Geometry(List<BigDecimal> coordinates) {}
    record Feature(Geometry geometry, Map<String, Object> properties) {}
    record Response(List<Feature> features) {}

    private final RestClient rest;

    public PhotonPlaceClient(RestClient.Builder builder) {
        this.rest = builder.defaultHeader("User-Agent", "SplitTrip (capstone)").build();
    }

    @Override
    public List<Place> search(String query, BigDecimal nearLat, BigDecimal nearLon) {
        UriComponentsBuilder b = UriComponentsBuilder.fromUriString("https://photon.komoot.io/api")
                .queryParam("q", "{q}").queryParam("lang", "it").queryParam("limit", 6);
        if (nearLat != null && nearLon != null) b.queryParam("lat", nearLat).queryParam("lon", nearLon);
        URI uri = b.encode().buildAndExpand(Map.of("q", query)).toUri(); // la codifica del testo è del builder, non nostra
        Response r = rest.get().uri(uri).retrieve().body(Response.class);
        List<Place> out = new ArrayList<>();
        if (r == null || r.features() == null) return out;
        for (Feature f : r.features()) {
            if (f.geometry() == null || f.geometry().coordinates() == null || f.geometry().coordinates().size() < 2) continue;
            Map<String, Object> p = f.properties() == null ? Map.of() : f.properties();
            String name = text(p, "name");
            List<String> parts = new ArrayList<>();
            for (String key : List.of("district", "city", "state", "country")) {
                String v = text(p, key);
                if (v != null && !v.equals(name) && !parts.contains(v)) parts.add(v);
            }
            if (name == null) {
                if (parts.isEmpty()) continue;
                name = parts.removeFirst();
            }
            out.add(new Place(name, String.join(", ", parts), f.geometry().coordinates().get(1), f.geometry().coordinates().get(0)));
        }
        return out;
    }

    private static String text(Map<String, Object> p, String key) {
        Object v = p.get(key);
        return v instanceof String s && !s.isBlank() ? s : null;
    }
}
```

```java
import org.springframework.stereotype.Service;

import java.math.BigDecimal;
import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.util.ArrayDeque;
import java.util.Collections;
import java.util.Deque;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Locale;
import java.util.Map;

import java.util.concurrent.ConcurrentHashMap;

/** Ricerca luoghi (D-46): valida, limita, mette in cache; se Photon non risponde, lista vuota. */
@Service
public class PlaceService {

    static final int MIN = 3, MAX = 100, PER_MINUTE = 30, CACHE_SIZE = 500;
    static final Duration CACHE_TTL = Duration.ofHours(24);
    private static final Logger log = LoggerFactory.getLogger(PlaceService.class);

    private record Cached(Instant expiresAt, List<Place> places) {}

    private final PlaceSearchClient client;
    private final Clock clock;
    private final Map<String, Cached> cache = Collections.synchronizedMap(new LinkedHashMap<>(64, 0.75f, true) {
        @Override protected boolean removeEldestEntry(Map.Entry<String, Cached> e) { return size() > CACHE_SIZE; }
    });
    private final Map<UUID, Deque<Instant>> searches = new ConcurrentHashMap<>();

    public PlaceService(PlaceSearchClient client, Clock clock) {
        this.client = client;
        this.clock = clock;
    }

    public List<Place> search(UUID userId, String rawQuery, String near) {
        String query = rawQuery == null ? "" : rawQuery.strip();
        if (query.length() < MIN) throw new FieldException("q", "Scrivi almeno 3 caratteri");
        if (query.length() > MAX) throw new FieldException("q", "Al massimo 100 caratteri");
        BigDecimal[] point = parseNear(near);
        Instant now = clock.instant();
        String key = query.toLowerCase(Locale.ITALIAN).replaceAll("\\s+", " ") + "|" + (point == null ? "" : point[0] + "," + point[1]);
        Cached hit = cache.get(key);
        if (hit != null && hit.expiresAt().isAfter(now)) return hit.places();
        if (!allow(userId, now)) throw new AppException(HttpStatus.TOO_MANY_REQUESTS, "Troppe ricerche", "Troppe ricerche, riprova tra poco");
        try {
            List<Place> found = client.search(query, point == null ? null : point[0], point == null ? null : point[1]);
            cache.put(key, new Cached(now.plus(CACHE_TTL), found));
            return found;
        } catch (RuntimeException e) {
            log.warn("Ricerca luoghi non disponibile: {}", e.getMessage());
            return List.of();
        }
    }

    /** «lat,lon» → coppia; qualsiasi altra cosa → null (si cerca senza vicinanza). */
    private static BigDecimal[] parseNear(String near) {
        if (near == null) return null;
        String[] parts = near.split(",");
        if (parts.length != 2) return null;
        try {
            BigDecimal lat = new BigDecimal(parts[0].strip()), lon = new BigDecimal(parts[1].strip());
            if (lat.abs().compareTo(BigDecimal.valueOf(90)) > 0 || lon.abs().compareTo(BigDecimal.valueOf(180)) > 0) return null;
            return new BigDecimal[] {lat, lon};
        } catch (NumberFormatException e) {
            return null;
        }
    }

    private boolean allow(UUID userId, Instant now) {
        Deque<Instant> times = searches.computeIfAbsent(userId, k -> new ArrayDeque<>());
        synchronized (times) {
            while (!times.isEmpty() && !times.peekFirst().isAfter(now.minus(Duration.ofMinutes(1)))) times.pollFirst();
            if (times.size() >= PER_MINUTE) return false;
            times.addLast(now);
            return true;
        }
    }
}
```

```java
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Clock;
import java.util.ArrayList;
import java.util.Collection;

/** Reazioni (D-47): sei emoji, una per persona, solo su messaggi di testo; il canale riceve il riepilogo dopo il commit. */
@Service
public class ReactionService {

    public static final List<String> ALLOWED = List.of("👍", "❤️", "😂", "😮", "😢", "🎉");

    private final MessageReactionRepository reactions;
    private final ChatMessageRepository messages;
    private final TripRepository trips;
    private final TripAccessService access;
    private final LivePublisher live;
    private final Clock clock;

    public ReactionService(MessageReactionRepository reactions, ChatMessageRepository messages, TripRepository trips,
                           TripAccessService access, LivePublisher live, Clock clock) {
        this.reactions = reactions;
        this.messages = messages;
        this.trips = trips;
        this.access = access;
        this.live = live;
        this.clock = clock;
    }

    @Transactional
    public void add(UUID tripId, UUID userId, UUID messageId, String emoji) {
        Participant me = prepare(tripId, userId, emoji);
        ChatMessage m = target(tripId, messageId);
        if (!reactions.existsByMessageIdAndParticipantIdAndEmoji(messageId, me.getId(), emoji)) {
            try {
                reactions.saveAndFlush(new MessageReaction(m, me, emoji, clock.instant()));
            } catch (DataIntegrityViolationException e) {
                // due tocchi insieme: la seconda inserzione trova la riga già presente, va bene così
            }
        }
        publish(tripId, messageId);
    }

    @Transactional
    public void remove(UUID tripId, UUID userId, UUID messageId, String emoji) {
        Participant me = prepare(tripId, userId, emoji);
        target(tripId, messageId);
        reactions.deleteOne(messageId, me.getId(), emoji);
        publish(tripId, messageId);
    }

    /** Riepilogo per ogni messaggio della pagina, nell'ordine delle emoji permesse. */
    @Transactional(readOnly = true)
    public Map<UUID, List<ReactionSummary>> summaries(Collection<UUID> messageIds) {
        Map<UUID, Map<String, List<UUID>>> grouped = new LinkedHashMap<>();
        if (!messageIds.isEmpty()) {
            for (Object[] row : reactions.findByMessageIds(messageIds)) {
                grouped.computeIfAbsent((UUID) row[0], k -> new LinkedHashMap<>())
                        .computeIfAbsent((String) row[1], k -> new ArrayList<>()).add((UUID) row[2]);
            }
        }
        Map<UUID, List<ReactionSummary>> out = new LinkedHashMap<>();
        for (UUID id : messageIds) {
            Map<String, List<UUID>> byEmoji = grouped.getOrDefault(id, Map.of());
            List<ReactionSummary> list = new ArrayList<>();
            for (String e : ALLOWED) {
                List<UUID> who = byEmoji.get(e);
                if (who != null && !who.isEmpty()) list.add(new ReactionSummary(e, who.size(), List.copyOf(who)));
            }
            out.put(id, list);
        }
        return out;
    }

    private Participant prepare(UUID tripId, UUID userId, String emoji) {
        Participant me = access.requireMember(tripId, userId);
        access.requireWritable(trips.findById(tripId).orElseThrow());
        if (!ALLOWED.contains(emoji)) throw new BadRequestException("Emoji non permessa");
        return me;
    }

    private ChatMessage target(UUID tripId, UUID messageId) {
        ChatMessage m = messages.findByIdAndTripId(messageId, tripId).orElseThrow(() -> new NotFoundException("Messaggio non trovato"));
        if (m.getKind() != ChatMessageKind.TEXT || m.isDeleted()) throw new ConflictException("Non si può reagire a questo messaggio");
        return m;
    }

    private void publish(UUID tripId, UUID messageId) {
        List<ReactionSummary> summary = summaries(List.of(messageId)).get(messageId);
        AfterCommit.run(() -> live.toTrip(tripId, "message.reacted", Map.of("id", messageId, "reactions", summary)));
    }
}
```

```java
            u.setEmail(email);

    }

        User u = users.findById(userId).orElseThrow();
        if (!encoder.matches(req.currentPassword(), u.getPasswordHash())) throw new FieldException("currentPassword", "Password attuale non corretta");
```

```java
package com.splittrip.home;

import com.splittrip.expense.BalanceService;
import com.splittrip.home.dto.HomeResponse;
import com.splittrip.home.dto.HomeResponse.*;
import com.splittrip.notification.NotificationRepository;
import com.splittrip.notification.dto.NotificationResponse;

import com.splittrip.weather.OpenMeteoClient.DayForecast;

import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.math.BigDecimal;
import java.time.Clock;
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Optional;
import java.util.UUID;

/** La Home in una chiamata (D-49): viaggio in evidenza, i miei saldi, le ultime novità, l'elenco. */
@Service
public class HomeService {

    private final TripService trips;
    private final ParticipantRepository participants;
    private final BalanceService balances;
    private final WeatherService weather;
    private final PhotoRepository photos;
    private final NotificationRepository notifications;
    private final Clock clock;

    public HomeService(TripService trips, ParticipantRepository participants, BalanceService balances, WeatherService weather,
                       PhotoRepository photos, NotificationRepository notifications, Clock clock) {
        this.trips = trips;
        this.participants = participants;
        this.balances = balances;
        this.weather = weather;
        this.photos = photos;
        this.notifications = notifications;
        this.clock = clock;
    }

    @Transactional(readOnly = true)
    public HomeResponse home(UUID userId) {
        LocalDate today = LocalDate.now(clock);
        List<TripSummaryResponse> all = trips.listForUser(userId);
        List<TripSummaryResponse> current = all.stream().filter(t -> t.status() != TripStatus.CLOSED).toList();
        List<TripSummaryResponse> past = all.stream().filter(t -> t.status() == TripStatus.CLOSED).toList();

        List<TripBalance> myBalances = new ArrayList<>();
        BigDecimal toReceive = BigDecimal.ZERO, toGive = BigDecimal.ZERO;
        int tripsToReceive = 0, tripsToGive = 0;
        for (TripSummaryResponse t : current) {
            BigDecimal net = myNet(t.id(), userId);
            if (net.signum() == 0) continue;
            myBalances.add(new TripBalance(t.id(), t.name(), t.currency(), net));
            if (net.signum() > 0) { toReceive = toReceive.add(net); tripsToReceive++; } else { toGive = toGive.add(net.negate()); tripsToGive++; }
        }

        Featured featured = pick(current, past, today).map(t -> featured(t, userId, today)).orElse(null);
        List<NotificationResponse> latest = notifications.findTop3ByUserIdOrderByCreatedAtDesc(userId).stream().map(NotificationResponse::from).toList();
        return new HomeResponse(featured, myBalances, new Totals(toReceive.setScale(2), toGive.setScale(2), tripsToReceive, tripsToGive), latest, new Trips(current, past));
    }

    /** In corso con la fine più vicina; altrimenti il prossimo in pianificazione; altrimenti l'ultimo chiuso. */
    static Optional<TripSummaryResponse> pick(List<TripSummaryResponse> current, List<TripSummaryResponse> past, LocalDate today) {
        Optional<TripSummaryResponse> ongoing = current.stream().filter(t -> t.status() == TripStatus.ONGOING).min(Comparator.comparing(TripSummaryResponse::endDate));
        if (ongoing.isPresent()) return ongoing;
        Optional<TripSummaryResponse> upcoming = current.stream().filter(t -> !t.endDate().isBefore(today)).min(Comparator.comparing(TripSummaryResponse::startDate));
        if (upcoming.isPresent()) return upcoming;
        Optional<TripSummaryResponse> anyPlanning = current.stream().min(Comparator.comparing(TripSummaryResponse::startDate));
        if (anyPlanning.isPresent()) return anyPlanning;
        return past.stream().max(Comparator.comparing(TripSummaryResponse::endDate));
    }

    private Featured featured(TripSummaryResponse t, UUID userId, LocalDate today) {
        int totalDays = (int) ChronoUnit.DAYS.between(t.startDate(), t.endDate()) + 1;
        String status = t.status() == TripStatus.CLOSED ? "PAST" : t.status() == TripStatus.ONGOING ? "ONGOING" : "UPCOMING";
        Integer daysUntil = status.equals("UPCOMING") ? (int) Math.max(0, ChronoUnit.DAYS.between(today, t.startDate())) : null;
        Integer dayOfTotal = status.equals("ONGOING") ? (int) Math.clamp(ChronoUnit.DAYS.between(t.startDate(), today) + 1, 1, totalDays) : null;
        DayForecast todayForecast = status.equals("PAST") ? null
                : weather.forecast(t.id(), userId).stream().filter(d -> d.date().equals(today)).findFirst().orElse(null);
        return new Featured(t, status, daysUntil, dayOfTotal, totalDays, photos.findLatestPhotoId(t.id()).orElse(null), todayForecast, myNet(t.id(), userId));
    }

    private BigDecimal myNet(UUID tripId, UUID userId) {
        return participants.findByTripIdAndUserIdAndLeftAtIsNull(tripId, userId)
                .flatMap(me -> balances.computeBalances(tripId).balances().stream().filter(b -> b.participantId().equals(me.getId())).findFirst())
                .map(b -> b.net()).orElse(BigDecimal.ZERO).setScale(2);
    }
}
```

```tsx
import { useEffect, useId, useRef, useState } from 'react'
import { placesApi } from '../api/placesApi'
import type { Place, PlaceValue } from '../api/types'

export type { PlaceValue }

type Props = {
  id: string; label: string; value: PlaceValue; onChange: (v: PlaceValue) => void
  near?: { latitude: number; longitude: number }; error?: string; placeholder?: string; hint?: string
}

/**
 * Combobox dei luoghi (D-46): dalla 3ª lettera, dopo 300 ms, propone fino a 6 luoghi; scelto uno, tiene le coordinate.
 * Il testo libero resta sempre valido: senza scelta si salva solo il nome.
 */
export function PlaceInput({ id, label, value, onChange, near, error, placeholder, hint }: Props) {
  const [options, setOptions] = useState<Place[]>([])
  const [open, setOpen] = useState(false)
  const [active, setActive] = useState(-1)
  const listId = useId()
  const timer = useRef<number | null>(null)
  const lastQuery = useRef('')

  useEffect(() => () => { if (timer.current) window.clearTimeout(timer.current) }, [])

  function type(text: string) {
    onChange({ name: text }) // scrivere ancora azzera le coordinate di una scelta precedente
    if (timer.current) window.clearTimeout(timer.current)
    const q = text.trim()
    if (q.length < 3) { setOptions([]); setOpen(false); return }
    timer.current = window.setTimeout(async () => {
      lastQuery.current = q
      try {
        const found = await placesApi.search(q, near)
        if (lastQuery.current !== q) return // è arrivata una ricerca più recente
        setOptions(found); setOpen(found.length > 0); setActive(-1)
      } catch { setOptions([]); setOpen(false) }
    }, 300)
  }

  function choose(p: Place) {
    onChange({ name: p.name, latitude: p.latitude, longitude: p.longitude })
    setOpen(false); setOptions([]); setActive(-1)
  }

  function onKeyDown(e: React.KeyboardEvent<HTMLInputElement>) {
    if (e.key === 'Escape') { setOpen(false); return }
    if (!open) return
    if (e.key === 'ArrowDown') { e.preventDefault(); setActive((a) => Math.min(a + 1, options.length - 1)) }
    if (e.key === 'ArrowUp') { e.preventDefault(); setActive((a) => Math.max(a - 1, 0)) }
    if (e.key === 'Enter' && active >= 0) { e.preventDefault(); choose(options[active]) }
  }

  return (
    <div className="field place-field">
      <label htmlFor={id}>{label}</label>
      <input id={id} role="combobox" aria-expanded={open} aria-controls={listId} aria-autocomplete="list"
        aria-activedescendant={open && active >= 0 ? `${listId}-${active}` : undefined} aria-invalid={error ? true : undefined}
        autoComplete="off" placeholder={placeholder} value={value.name}
        onChange={(e) => type(e.target.value)} onKeyDown={onKeyDown} onBlur={() => window.setTimeout(() => setOpen(false), 150)} />
      {open && (
        <ul id={listId} role="listbox" className="place-options">
          {options.map((p, i) => (
            <li key={`${p.name}-${p.latitude}-${p.longitude}`} id={`${listId}-${i}`} role="option" aria-selected={i === active}
              className={i === active ? 'active' : ''} onMouseDown={(e) => { e.preventDefault(); choose(p) }}>
              <strong>{p.name}</strong>{p.detail && <small className="muted">{p.detail}</small>}
            </li>
          ))}
        </ul>
      )}
      <span className="sr-only" aria-live="polite">{open ? `${options.length} ${options.length === 1 ? 'proposta' : 'proposte'}` : ''}</span>
      {hint && !error && <small className="muted">{hint}</small>}
      {error && <p className="field-error"><span>{error}</span></p>}
    </div>
  )
}
```
