# v3.2 «Giochi, riepilogo e tema» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** tema scuro con logo, sfondo e footer nuovi; «Chi offre?»; riepilogo di fine viaggio con «Indovina il totale», badge, classifiche e immagine per le storie; pubblicati su Render con tag `v3.2`.

**Architecture:** il backend aggiunge il package `wrapped` (un endpoint che calcola tutto il riepilogo con una query per tabella, un calcolatore di badge puro, le ipotesi in una tabella nuova) e la preferenza `theme`. Il frontend aggiunge i token scuri e `ThemeRoot`, il componente `Logo`, la ruota «Chi offre?» (solo frontend, apre il modulo spesa precompilato), le pagine del riepilogo e il disegno dell'immagine con Canvas. Niente librerie nuove.

**Tech Stack:** Spring Boot 4.1 / Java 25 / PostgreSQL / Flyway (V8); React 19, TanStack Query, react-hook-form + zod, Motion, Canvas 2D; Vitest + Testing Library + MSW.

**Spec:** `docs/superpowers/specs/2026-10-16-v3.2-giochi-riepilogo-tema-design.md`

## Global Constraints

- Soldi: `BigDecimal` scala 2 HALF_UP, mai `double`. Date ISO nell'API, italiane a schermo.
- Schema solo via Flyway (`V8__giochi_tema.sql`); `ddl-auto=validate`; mai toccare V1–V7.
- Id utente sempre dal token (`@CurrentUserId`). Ogni service su un viaggio inizia con `TripAccessService.requireMember`.
- Errori sempre in Problem Details; errori di campo con `FieldException(field, message)`; conflitti con `ConflictException`.
- Riepilogo aperto quando `status == CLOSED` oppure `today > endDate` (stessa regola di `HomeService.displayStatus`): altrimenti 409 «Il riepilogo arriva a fine viaggio».
- Spese e rimborsi nel cestino esclusi (`@SoftDelete`): le query partono sempre da `Expense`/`Settlement`.
- Badge (D-55): almeno uno a testa, pari merito a chi è entrato prima (`joinedAt`), zero non vince; classifiche solo su foto, messaggi, reazioni ricevute.
- Immagine per le storie (D-56): Canvas nel browser, nessun invio al server, nessuna email né saldo personale.
- Tema (D-57): `SYSTEM|LIGHT|DARK` sull'account; `data-theme` su `<html>` prima del primo disegno; CSP senza `unsafe-inline` (hash dello script).
- Accessibilità (D-24): mai solo il colore, 44 px, verdetti annunciati a parole, animazioni spente con `reduceMotion()`, contrasto AA in entrambi i temi.
- Copy in italiano; icone Material Symbols; le emoji solo nei contenuti (reazioni, titoli dei badge, griglia).
- TDD: test visto fallire prima del codice. I commit li fa l'autrice: a fine task «Puoi committare: `<messaggio>`» (+ Stage All) e stop. Mai `git commit`/`git push`, nessuna riga `Co-Authored-By`.

`BadgeCalculator.java`:

```java
package com.splittrip.wrapped;

import com.splittrip.wrapped.dto.WrappedResponse.Badge;
import com.splittrip.wrapped.dto.WrappedResponse.BadgeCode;
import com.splittrip.wrapped.dto.WrappedResponse.Person;

import java.math.BigDecimal;
import java.text.NumberFormat;
import java.time.Instant;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashSet;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Optional;
import java.util.Set;
import java.util.UUID;
import java.util.function.Function;

/** Badge di fine viaggio (D-55): almeno uno a testa, pari merito a chi è entrato prima, zero non vince. Puro: niente Spring. */
public final class BadgeCalculator {

    private BadgeCalculator() {}

    private static final NumberFormat MONEY = NumberFormat.getNumberInstance(Locale.ITALY);
    static { MONEY.setMinimumFractionDigits(2); MONEY.setMaximumFractionDigits(2); }

    public static List<Badge> compute(List<Person> people, Map<UUID, Instant> firstSettlementAt) {
        List<Badge> out = new ArrayList<>();
        Set<UUID> winners = new HashSet<>();
        award(out, winners, people, BadgeCode.BANKER, "💰 Il banchiere", Person::paid, p -> "ha anticipato " + MONEY.format(p.paid()));
        award(out, winners, people, BadgeCode.PHOTOGRAPHER, "📸 Il fotografo", p -> BigDecimal.valueOf(p.photos()), p -> p.photos() + " foto");
        award(out, winners, people, BadgeCode.VOICE, "💬 La voce del gruppo", p -> BigDecimal.valueOf(p.messages()), p -> p.messages() + " messaggi");
        award(out, winners, people, BadgeCode.FOODIE, "🍝 Il buongustaio", Person::foodPaid, p -> "ha offerto cibo per " + MONEY.format(p.foodPaid()));
        firstSettlementAt.entrySet().stream().min(Map.Entry.comparingByValue()).map(Map.Entry::getKey)
                .flatMap(id -> people.stream().filter(p -> p.participantId().equals(id)).findFirst())
                .ifPresent(p -> { out.add(new Badge(p.participantId(), BadgeCode.PUNCTUAL, "⏱️ Il puntuale", "primo a saldare")); winners.add(p.participantId()); });
        award(out, winners, people, BadgeCode.LOVED, "❤️ Il più amato", p -> BigDecimal.valueOf(p.reactionsReceived()), p -> p.reactionsReceived() + " reazioni ricevute");
        // l'esploratore serve almeno due luoghi: un luogo solo è una foto con un nome
        award(out, winners, people, BadgeCode.EXPLORER, "🧭 L'esploratore", p -> BigDecimal.valueOf(p.places() >= 2 ? p.places() : 0), p -> "foto in " + p.places() + " luoghi");
        for (Person p : people) {
            if (!winners.contains(p.participantId())) out.add(new Badge(p.participantId(), BadgeCode.COMPANION, "🧳 Compagno di viaggio", "c'era, e tanto basta"));
        }
        // ordine stabile: per persona nell'ordine d'ingresso, poi per codice
        List<UUID> order = people.stream().sorted(Comparator.comparing(Person::joinedAt)).map(Person::participantId).toList();
        out.sort(Comparator.<Badge>comparingInt(b -> order.indexOf(b.participantId())).thenComparing(b -> b.code().ordinal()));
        return out;
    }

    private static void award(List<Badge> out, Set<UUID> winners, List<Person> people, BadgeCode code, String title,
                              Function<Person, BigDecimal> value, Function<Person, String> detail) {
        Optional<Person> best = people.stream()
                .filter(p -> value.apply(p).signum() > 0)
                .max(Comparator.comparing(value).thenComparing(Person::joinedAt, Comparator.reverseOrder())); // a pari valore vince joinedAt minore
        best.ifPresent(p -> { out.add(new Badge(p.participantId(), code, title, detail.apply(p))); winners.add(p.participantId()); });
    }
}
```

```java
import com.splittrip.chat.ChatMessageRepository;

/** Il riepilogo di fine viaggio (D-53): una query per tabella, badge dal calcolatore, ipotesi del gioco (D-54). */
@Service
public class WrappedService {

    private final TripRepository trips;
    private final ParticipantRepository participants;
    private final ExpenseRepository expenses;
    private final SettlementRepository settlements;
    private final PhotoRepository photos;
    private final ChatMessageRepository messages;
    private final MessageReactionRepository reactions;
    private final WrappedGuessRepository guesses;
    private final BalanceService balances;
    private final TripAccessService access;
    private final Clock clock;

    public WrappedService(TripRepository trips, ParticipantRepository participants, ExpenseRepository expenses, SettlementRepository settlements,
                          PhotoRepository photos, ChatMessageRepository messages, MessageReactionRepository reactions, WrappedGuessRepository guesses,
                          BalanceService balances, TripAccessService access, Clock clock) {
        this.trips = trips; this.participants = participants; this.expenses = expenses; this.settlements = settlements; this.photos = photos;
        this.messages = messages; this.reactions = reactions; this.guesses = guesses; this.balances = balances; this.access = access; this.clock = clock;
    }

    @Transactional(readOnly = true)
    public WrappedResponse get(UUID tripId, UUID userId) {
        Participant me = access.requireMember(tripId, userId);
        Trip trip = requireOpen(tripId);
        List<Participant> all = participants.findByTripIdOrderByJoinedAtAsc(tripId);
        Map<UUID, Participant> byId = new LinkedHashMap<>();
        all.forEach(p -> byId.put(p.getId(), p));
        Map<UUID, UUID> participantByUser = new HashMap<>();
        all.stream().filter(Participant::hasAccount).forEach(p -> participantByUser.put(p.userId(), p.getId()));

        // spese attive (la query esclude il cestino)
        List<Expense> active = expenses.findAllByTripIdWithShares(tripId);
        BigDecimal groupTotal = active.stream().map(Expense::getAmount).reduce(BigDecimal.ZERO, BigDecimal::add);
        Map<String, BigDecimal> byCat = new LinkedHashMap<>();
        Map<LocalDate, BigDecimal> byDay = new HashMap<>();
        Map<UUID, BigDecimal> paid = new HashMap<>(), foodPaid = new HashMap<>();
        Set<UUID> withShare = new HashSet<>();
        Expense biggest = null;
        for (Expense e : active) {
            byCat.merge(e.getCategory().name(), e.getAmount(), BigDecimal::add);
            byDay.merge(e.getDate(), e.getAmount(), BigDecimal::add);
            paid.merge(e.getPayer().getId(), e.getAmount(), BigDecimal::add);
            if (e.getCategory().name().equals("FOOD")) foodPaid.merge(e.getPayer().getId(), e.getAmount(), BigDecimal::add);
            e.getShares().forEach(s -> withShare.add(s.getParticipant().getId()));
            if (biggest == null || e.getAmount().compareTo(biggest.getAmount()) > 0) biggest = e;
        }
        List<Category> categories = byCat.entrySet().stream()
                .sorted(Map.Entry.<String, BigDecimal>comparingByValue().reversed())
                .map(en -> new Category(en.getKey(), money(en.getValue()), groupTotal.signum() == 0 ? 0
                        : en.getValue().multiply(BigDecimal.valueOf(100)).divide(groupTotal, 0, RoundingMode.HALF_UP).intValue()))
                .toList();
        Day priciest = byDay.entrySet().stream().max(Map.Entry.comparingByValue()).map(en -> new Day(en.getKey(), money(en.getValue()))).orElse(null);
        Record record = biggest == null ? null : new Record(biggest.getDescription(), money(biggest.getAmount()), biggest.getPayer().getDisplayName());

        // foto: momenti (prima quelle con luogo), conteggi e luoghi per persona
        List<Object[]> photoRows = photos.findWrappedRows(tripId);
        Map<UUID, Integer> photoCount = new HashMap<>();
        Map<UUID, Set<String>> places = new HashMap<>();
        for (Object[] r : photoRows) {
            UUID pid = participantByUser.get((UUID) r[0]);
            if (pid == null) continue;
            photoCount.merge(pid, 1, Integer::sum);
            if (r[1] != null) places.computeIfAbsent(pid, k -> new HashSet<>()).add((String) r[1]);
        }
        List<Moment> moments = photoRows.stream()
                .sorted(Comparator.comparing((Object[] r) -> r[1] == null).thenComparing(r -> (Instant) r[2], Comparator.reverseOrder()))
                .limit(6)
                .map(r -> new Moment((UUID) r[3], (String) r[4], (String) r[1], (BigDecimal) r[5], (BigDecimal) r[6]))
                .toList();
        UUID cover = photoRows.isEmpty() ? null : (UUID) photoRows.getFirst()[3];

        Map<UUID, Integer> msgCount = new HashMap<>();
        for (Object[] r : messages.countTextByAuthor(tripId)) msgCount.put((UUID) r[0], ((Long) r[1]).intValue());
        Map<UUID, Integer> reactCount = new HashMap<>();
        for (Object[] r : reactions.countReceivedByAuthor(tripId)) reactCount.put((UUID) r[0], ((Long) r[1]).intValue());
        Map<UUID, Instant> firstSettlement = new HashMap<>();
        for (Object[] r : settlements.firstSettlementByPayer(tripId)) firstSettlement.put((UUID) r[0], (Instant) r[1]);

        List<Person> people = all.stream().map(p -> new Person(p.getId(), p.getDisplayName(), p.hasAccount(), p.userId(), p.getJoinedAt(),
                money(paid.getOrDefault(p.getId(), BigDecimal.ZERO)), photoCount.getOrDefault(p.getId(), 0), msgCount.getOrDefault(p.getId(), 0),
                reactCount.getOrDefault(p.getId(), 0), money(foodPaid.getOrDefault(p.getId(), BigDecimal.ZERO)), places.getOrDefault(p.getId(), Set.of()).size())).toList();

        BalancesResponse bal = balances.computeBalances(tripId);
        boolean settled = bal.balances().stream().allMatch(b -> b.net().signum() == 0);
        int nights = (int) ChronoUnit.DAYS.between(trip.getStartDate(), trip.getEndDate());
        int sharers = Math.max(1, withShare.size());
        return new WrappedResponse(
                new WrappedResponse.Trip(trip.getId(), trip.getName(), trip.getDestination(), trip.getStartDate(), trip.getEndDate(), nights, all.size(), trip.getCurrency(), cover),
                new Totals(money(groupTotal), active.isEmpty() ? money(BigDecimal.ZERO) : groupTotal.divide(BigDecimal.valueOf(sharers), 2, RoundingMode.HALF_UP),
                        active.size(), photoRows.size(), msgCount.values().stream().mapToInt(Integer::intValue).sum(), reactCount.values().stream().mapToInt(Integer::intValue).sum()),
                categories, record, priciest, moments, people, BadgeCalculator.compute(people, firstSettlement),
                new Settlement(settled, bal.suggestedTransfers().size()), guess(tripId, me.getId(), byId, groupTotal));
    }

    public void guess(UUID tripId, UUID userId, BigDecimal amount) {
        Participant me = access.requireMember(tripId, userId);
        requireOpen(tripId);
        if (guesses.insertIfAbsent(tripId, me.getId(), amount.setScale(2, RoundingMode.HALF_UP), clock.instant()) == 0) {
            throw new ConflictException("Hai già dato la tua ipotesi");
        }
    }

    private Trip requireOpen(UUID tripId) {
        Trip trip = trips.findById(tripId).orElseThrow();
        if (!HomeService.isOver(trip.getStatus(), trip.getEndDate(), LocalDate.now(clock))) throw new ConflictException("Il riepilogo arriva a fine viaggio");
        return trip;
    }

    /** Le ipotesi altrui si vedono solo dopo aver dato la propria (D-54). */
    private Guess guess(UUID tripId, UUID myParticipantId, Map<UUID, Participant> byId, BigDecimal groupTotal) {
        List<Object[]> rows = guesses.findByTripId(tripId);
        BigDecimal mine = rows.stream().filter(r -> r[0].equals(myParticipantId)).map(r -> money((BigDecimal) r[1])).findFirst().orElse(null);
        if (mine == null) return new Guess(null, rows.size(), null);
        List<GuessEntry> others = rows.stream()
                .map(r -> new GuessEntry((UUID) r[0], byId.get((UUID) r[0]).getDisplayName(), money((BigDecimal) r[1]), money(((BigDecimal) r[1]).subtract(groupTotal).abs())))
                .sorted(Comparator.comparing(GuessEntry::diff))
                .toList();
        return new Guess(mine, rows.size(), others);
    }

    private static BigDecimal money(BigDecimal v) { return v.setScale(2, RoundingMode.HALF_UP); }
}
```

```ts
export type ThemePref = 'SYSTEM' | 'LIGHT' | 'DARK'
export type Resolved = 'light' | 'dark'
export const THEME_COLOR: Record<Resolved, string> = { light: '#00685c', dark: '#0f1620' }

export function resolveTheme(pref: ThemePref | undefined, systemDark: boolean): Resolved {
  if (pref === 'DARK') return 'dark'
  if (pref === 'LIGHT') return 'light'
  return systemDark ? 'dark' : 'light'
}

/** Imposta il tema sulla pagina: i token CSS leggono data-theme, il browser il colore della barra. */
export function applyTheme(resolved: Resolved) {
  document.documentElement.dataset.theme = resolved
  document.querySelector('meta[name="theme-color"]')?.setAttribute('content', THEME_COLOR[resolved])
}
```

```tsx
/** D-57: il tema dell'account (o del sistema) applicato a <html>; lo script in index.html l'ha già messo prima del primo disegno. */
export function ThemeRoot({ children }: { children: ReactNode }) {
  const { auth } = useAuth()
  const pref = auth?.user.theme ?? 'SYSTEM'
  useEffect(() => {
    const mq = window.matchMedia('(prefers-color-scheme: dark)')
    const apply = () => applyTheme(resolveTheme(pref, mq.matches))
    apply()
    mq.addEventListener('change', apply)
    return () => mq.removeEventListener('change', apply)
  }, [pref])
  return children
}
```

`wheel.ts`:

```ts
/** Numero in [0, 1) davvero casuale: la ruota non deve essere prevedibile. */
export function cryptoRandom(): number {
  const buf = new Uint32Array(1)
  crypto.getRandomValues(buf)
  return buf[0] / 2 ** 32
}

export function pickIndex(count: number, random: () => number = cryptoRandom): number {
  return Math.min(count - 1, Math.floor(random() * count))
}

/** Gradi di rotazione (in senso orario) perché la freccia in alto punti al centro dello spicchio scelto, dopo `turns` giri. */
export function wheelRotation(index: number, count: number, turns = 5): number {
  const slice = 360 / count
  const center = index * slice + slice / 2
  return turns * 360 + (360 - center)
}

export const WHEEL_COLORS = ['var(--accent)', 'var(--negative-2)', 'var(--amber)', 'var(--accent-2)', '#8b7cf6', '#4aa3df'] as const
```

```tsx
import * as m from 'motion/react-m'
import { useState } from 'react'
import { useNavigate } from 'react-router'
import type { Participant, Trip } from '../../shared/api/types'
import { playChime } from '../../shared/live/sound'
import { Avatar } from '../../shared/ui/Avatar'
import { Button } from '../../shared/ui/Button'
import { Icon } from '../../shared/ui/Icon'
import { Modal } from '../../shared/ui/Modal'
import { reduceMotion } from '../../shared/utils/motion'
import type { ExpensePrefill } from '../expenses/ExpenseFormPage'
import { Confetti } from './Confetti'
import { cryptoRandom, pickIndex, WHEEL_COLORS, wheelRotation } from './wheel'

type Props = { trip: Trip; me: Participant; open: boolean; onClose: () => void; random?: () => number }

/** «Chi offre?» (D-52): la ruota sceglie tra chi c'è; il verdetto apre la spesa già compilata. Solo frontend. */
export function WhoPays({ trip, me, open, onClose, random = cryptoRandom }: Props) {
  const navigate = useNavigate()
  const active = trip.participants.filter((p) => !('leftAt' in p && p.leftAt))
  const [chosen, setChosen] = useState<Set<string>>(() => new Set(active.filter((p) => p.userId !== null).map((p) => p.id)))
  const [rotation, setRotation] = useState(0)
  const [spinning, setSpinning] = useState(false)
  const [winner, setWinner] = useState<Participant | null>(null)
  const players = active.filter((p) => chosen.has(p.id))
  const slice = 360 / Math.max(players.length, 1)

  function spin() {
    const index = pickIndex(players.length, random)
    const target = players[index]
    setWinner(null)
    if (reduceMotion()) { setWinner(target); if (isSoundOn()) playChime(); return }
    setSpinning(true)
    setRotation((r) => r - (r % 360) + wheelRotation(index, players.length))
    window.setTimeout(() => { setSpinning(false); setWinner(target); if (isSoundOn()) playChime() }, 3000)
  }

  function register() {
    if (!winner) return
    const prefill: ExpensePrefill = { payerId: winner.id, participantIds: players.map((p) => p.id), category: 'FOOD', date: new Date().toISOString().slice(0, 10), description: '' }
    onClose()
    navigate(`/trips/${trip.id}/expenses/new`, { state: { prefill } })
  }

  const toggle = (id: string) => setChosen((prev) => { const next = new Set(prev); if (next.has(id)) next.delete(id); else next.add(id); return next })

  return (
    <Modal open={open} title="Chi offre?" onClose={onClose}>
      <p className="muted">Spunta chi c'è, poi gira: ognuno ha le stesse probabilità.</p>
      <div className="chips who-chips" role="group" aria-label="Chi c'è">
        {active.map((p) => (
          <label key={p.id} className={`chip ${chosen.has(p.id) ? 'active' : ''}`}>
            <input type="checkbox" checked={chosen.has(p.id)} onChange={() => toggle(p.id)} disabled={spinning} aria-label={p.displayName} />
            <Avatar name={p.displayName} size="sm" userId={p.userId} hasAvatar={p.hasAvatar} me={p.id === me.id} />{p.displayName}
          </label>
        ))}
      </div>
      <div className="wheel-wrap">
        <span className="wheel-pointer" aria-hidden="true" />
        <m.svg className="wheel" viewBox="-50 -50 100 100" aria-hidden="true" animate={{ rotate: rotation }}
          transition={{ duration: reduceMotion() ? 0 : 3, ease: [0.15, 0.85, 0.25, 1] }}>
          {players.map((p, i) => {
            const a0 = (i * slice - 90) * (Math.PI / 180), a1 = ((i + 1) * slice - 90) * (Math.PI / 180)
            const d = players.length === 1 ? 'M0,0 m-50,0 a50,50 0 1,0 100,0 a50,50 0 1,0 -100,0'
              : `M0,0 L${50 * Math.cos(a0)},${50 * Math.sin(a0)} A50,50 0 ${slice > 180 ? 1 : 0},1 ${50 * Math.cos(a1)},${50 * Math.sin(a1)} Z`
            const mid = ((i + 0.5) * slice - 90) * (Math.PI / 180)
            return (
              <g key={p.id}>
                <path d={d} fill={WHEEL_COLORS[i % WHEEL_COLORS.length]} stroke="var(--surface)" strokeWidth="1" />
                <text x={30 * Math.cos(mid)} y={30 * Math.sin(mid)} fontSize="6" fontWeight="700" fill="#fff" textAnchor="middle" dominantBaseline="middle"
                  transform={`rotate(${(i + 0.5) * slice} ${30 * Math.cos(mid)} ${30 * Math.sin(mid)})`}>{p.displayName.split(' ')[0]}</text>
              </g>
            )
          })}
        </m.svg>
      </div>
      <Confetti active={winner !== null} />
      <p role="status" className="wheel-verdict" aria-live="assertive">{winner ? `Offre ${winner.displayName}!` : spinning ? 'La ruota gira…' : ''}</p>
      <div className="modal-actions">
        {winner ? (
          <>
            <Button onClick={register}><Icon name="receipt_long" />Registra la spesa</Button>
            <Button variant="secondary" onClick={spin}>Rigira</Button>
          </>
        ) : (
          <Button onClick={spin} disabled={players.length < 2 || spinning} className="wheel-spin">Gira!</Button>
        )}
        <Button variant="secondary" onClick={onClose}>Chiudi</Button>
      </div>
    </Modal>
  )
}
```

```ts
import { drawLogo } from '../../shared/ui/globe'

export type StoryData = { name: string; dates: string; total: number; perPerson: number; photos: number; messages: number; currency: string; badges: { title: string }[] }
export const STORY_W = 1080, STORY_H = 1920
const FONT = 'DM Sans, system-ui, sans-serif'

/** Disegna l'immagine per le storie (D-56): sfondo (foto sfocata o gradiente), titolo, totale, numeri, badge, firma. Nessun dato personale. */
export function drawStory(ctx: CanvasRenderingContext2D, d: StoryData, cover?: CanvasImageSource & { width: number; height: number }) {
  if (cover) {
    // ritaglio 9:16 centrato, poi sfocatura e velo scuro per leggere il testo
    const targetRatio = STORY_W / STORY_H
    let sw = cover.width, sh = cover.height, sx = 0, sy = 0
    if (sw / sh > targetRatio) { sw = Math.round(sh * targetRatio); sx = Math.round((cover.width - sw) / 2) } else { sh = Math.round(sw / targetRatio); sy = Math.round((cover.height - sh) / 2) }
    ctx.filter = 'blur(18px)'
    ctx.drawImage(cover, sx, sy, sw, sh, 0, 0, STORY_W, STORY_H)
    ctx.filter = 'none'
    ctx.fillStyle = 'rgba(15, 22, 32, 0.62)'
    ctx.fillRect(0, 0, STORY_W, STORY_H)
  } else {
    const g = ctx.createLinearGradient(0, 0, STORY_W, STORY_H)
    g.addColorStop(0, '#2347b8'); g.addColorStop(0.6, '#0f1620'); g.addColorStop(1, '#a3305e')
    ctx.fillStyle = g
    ctx.fillRect(0, 0, STORY_W, STORY_H)
  }
  ctx.textAlign = 'center'
  ctx.fillStyle = '#ffffff'
  ctx.font = `800 88px ${FONT}`; ctx.fillText(d.name, STORY_W / 2, 360)
  ctx.font = `500 40px ${FONT}`; ctx.fillStyle = '#97f3e2'; ctx.fillText(d.dates, STORY_W / 2, 430)
  ctx.fillStyle = '#ffffff'
  ctx.font = `800 150px ${FONT}`; ctx.fillText(formatMoney(d.total, d.currency), STORY_W / 2, 760)
  ctx.font = `500 44px ${FONT}`; ctx.fillStyle = '#97f3e2'; ctx.fillText('in tutto', STORY_W / 2, 830)
  const cols = [[formatMoney(d.perPerson, d.currency), 'a persona'], [String(d.photos), 'foto'], [String(d.messages), 'messaggi']]
  cols.forEach(([v, l], i) => {
    const x = STORY_W / 2 + (i - 1) * 320
    ctx.fillStyle = '#ffffff'; ctx.font = `800 64px ${FONT}`; ctx.fillText(v, x, 1010)
    ctx.fillStyle = '#97f3e2'; ctx.font = `500 36px ${FONT}`; ctx.fillText(l, x, 1060)

  ctx.fillStyle = '#ffffff'; ctx.font = `700 48px ${FONT}`
```
