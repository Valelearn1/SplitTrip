# SplitTrip v2 «Social» — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** liste condivise con assegnatario, foto del viaggio con mappa, notifiche in-app, più scontrino sulla spesa, foto profilo e meteo della destinazione.

**Architecture:** una migrazione `V4__social.sql`; quattro package nuovi nel backend (`todo`, `photo`, `notification`, `weather`) più l'avatar in `user`; i service pubblicano **eventi interni** e un listener dopo il commit scrive le notifiche (D-36); le immagini sono ridotte dal telefono e riscritte dal server con una classe pura `ImageProcessor` (D-35); nel frontend una barra a cinque voci, `AuthImage` per le immagini protette dal Bearer, Leaflet per la mappa.

**Tech Stack:** Spring Boot 4.1 / Java 25 / Hibernate 7 / Flyway / `ImageIO` + TwelveMonkeys WebP / `RestClient` · React 19 / TS / TanStack Query / RHF + Zod / `leaflet` + `react-leaflet` / `exifr` / Vitest + msw.

**Spec:** `docs/superpowers/specs/2026-10-14-v2-social-design.md` (le sezioni citate come §N sono di questa spec).

## Global Constraints

- Schema solo via Flyway; `ddl-auto=validate`; **mai toccare V1, V2, V3**.
- Ogni service su un viaggio inizia con `TripAccessService.requireMember / requireOrganizer`; id utente sempre dal token.
- Errori Problem Details in italiano; `FieldException` per i 400 di campo.
- I soldi puntano a `participants(id)`; l'assegnatario di una voce è un **partecipante**; chi carica foto, crea liste e riceve notifiche è un **utente** (ha un account).
- Hard delete per liste, voci, foto, notifiche (D-15); soft delete resta solo su spese e rimborsi.
- Immagini: 3 MB per upload, 200 foto per viaggio, 2 elaborazioni in parallelo; nel DB solo JPEG riscritti dal server; coordinate solo con consenso (D-35).
- Nessuna immagine pubblica: Bearer su ogni byte, nessun token in query string.
- Accessibilità D-24: mai solo il colore, `aria-label` sui controlli iconici, lista testuale sotto la mappa, `prefers-reduced-motion`.
- TDD; un commit per task su `main`; i commit li fa l'autrice («Puoi committare: …»); nessuna riga `Co-Authored-By`.
- Suite di partenza: BE 100, FE 37, verdi.

## Review Focus

1. **Foto PNG con trasparenza** caricata come scontrino o foto: deve diventare un JPEG con sfondo bianco, non nero né un errore → test in Task 4.
2. **Coordinate nel body senza consenso** (il client manda `latitude`/`longitude` ma la casella era spenta): il frontend non deve mandarle; il backend, se arriva una sola delle due, risponde 400 sul campo, non salva metà posizione → test in Task 5 (backend) e Task 10 (frontend).
3. **Assegnare una voce a un partecipante che ha lasciato il viaggio**: 400 «deve far parte del viaggio», non un'assegnazione a un fantasma → test in Task 3.
4. **Una notifica che punta a una spesa poi cancellata**: aprirla porta alla pagina spesa che dice «Spesa non trovata», senza crash; la notifica resta leggibile → test in Task 11.
5. **Open-Meteo lento o giù**: la panoramica si apre comunque, senza widget, entro i 3 s di timeout; nessun 500 → test in Task 7.

```sql
-- v2 «Social» (D-34..D-37; spec 2026-10-14-v2-social-design.md §3)
CREATE TABLE todo_lists (
    id         UUID PRIMARY KEY,
    trip_id    UUID NOT NULL REFERENCES trips (id) ON DELETE CASCADE,
    title      VARCHAR(60) NOT NULL,
    type       VARCHAR(16) NOT NULL CHECK (type IN ('PACKING', 'GENERAL')),
    created_by UUID NOT NULL REFERENCES users (id),
    created_at TIMESTAMPTZ NOT NULL
);
CREATE INDEX idx_todo_lists_trip ON todo_lists (trip_id);

CREATE TABLE todo_items (
    id                      UUID PRIMARY KEY,
    list_id                 UUID NOT NULL REFERENCES todo_lists (id) ON DELETE CASCADE,
    text                    VARCHAR(120) NOT NULL,
    done                    BOOLEAN NOT NULL DEFAULT FALSE,
    assignee_participant_id UUID REFERENCES participants (id),
    created_by              UUID NOT NULL REFERENCES users (id),
    created_at              TIMESTAMPTZ NOT NULL,
    updated_at              TIMESTAMPTZ NOT NULL
);
CREATE INDEX idx_todo_items_list ON todo_items (list_id);

CREATE TABLE photos (
    id          UUID PRIMARY KEY,
    trip_id     UUID NOT NULL REFERENCES trips (id) ON DELETE CASCADE,
    uploader_id UUID NOT NULL REFERENCES users (id),
    kind        VARCHAR(8) NOT NULL CHECK (kind IN ('PHOTO', 'RECEIPT')),
    expense_id  UUID REFERENCES expenses (id) ON DELETE CASCADE,
    image       BYTEA NOT NULL,
    thumbnail   BYTEA NOT NULL,
    width       INTEGER NOT NULL,
    height      INTEGER NOT NULL,
    caption     VARCHAR(200),
    taken_at    TIMESTAMPTZ,
    latitude    NUMERIC(9, 6),
    longitude   NUMERIC(9, 6),
    created_at  TIMESTAMPTZ NOT NULL,
    CONSTRAINT photos_kind_expense CHECK ((kind = 'RECEIPT') = (expense_id IS NOT NULL)),
    CONSTRAINT photos_location CHECK ((latitude IS NULL) = (longitude IS NULL)
        AND (latitude IS NULL OR (latitude BETWEEN -90 AND 90 AND longitude BETWEEN -180 AND 180)))
);
CREATE INDEX idx_photos_trip_created ON photos (trip_id, created_at DESC);
CREATE UNIQUE INDEX photos_receipt_unique ON photos (expense_id) WHERE kind = 'RECEIPT';

CREATE TABLE user_avatars (
    user_id    UUID PRIMARY KEY REFERENCES users (id) ON DELETE CASCADE,
    image      BYTEA NOT NULL,
    updated_at TIMESTAMPTZ NOT NULL
);

CREATE TABLE notifications (
    id         UUID PRIMARY KEY,
    user_id    UUID NOT NULL REFERENCES users (id) ON DELETE CASCADE,
    trip_id    UUID NOT NULL REFERENCES trips (id) ON DELETE CASCADE,
    type       VARCHAR(24) NOT NULL CHECK (type IN ('EXPENSE_ADDED', 'SETTLEMENT_ADDED', 'PARTICIPANT_JOINED', 'TODO_ASSIGNED')),
    message    VARCHAR(200) NOT NULL,
    link       VARCHAR(200) NOT NULL,
    read_at    TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL
);
CREATE INDEX idx_notifications_user ON notifications (user_id, read_at, created_at DESC);

-- Coordinate della destinazione per il meteo, calcolate al primo uso (spec v2 §4)
ALTER TABLE trips ADD COLUMN latitude NUMERIC(9, 6), ADD COLUMN longitude NUMERIC(9, 6);
```

```java
package com.splittrip.notification;

import java.math.BigDecimal;
import java.text.DecimalFormat;
import java.text.DecimalFormatSymbols;
import java.util.Locale;

/** Testi delle notifiche, già in italiano: chi legge non deve fare conti. */
final class NotificationMessages {
    private static final int MAX = 200;
    private NotificationMessages() {}

    static String money(BigDecimal amount) {
        return new DecimalFormat("#,##0.00", DecimalFormatSymbols.getInstance(Locale.ITALY)).format(amount) + " €";
    }

    static String expense(String actorName, String description, BigDecimal share) {
        String tail = "» (tua quota " + money(share) + ")";
        String head = actorName + " ha aggiunto «";
        return head + clip(description, MAX - head.length() - tail.length()) + tail;
    }

    static String settlement(String actorName, BigDecimal amount, boolean youReceive, String otherName) {
        return youReceive
                ? actorName + " ha registrato un rimborso di " + money(amount) + " a te"
                : actorName + " ha registrato un tuo rimborso di " + money(amount) + " a " + otherName;
    }

    static String joined(String name) { return name + " è entrata nel viaggio"; }

    static String todo(String actorName, String itemText, String listTitle) {
        String head = actorName + " ti ha assegnato «";
        String tail = "» (" + listTitle + ")";
        return head + clip(itemText, MAX - head.length() - tail.length()) + tail;
    }

    private static String clip(String s, int max) {
        return s.length() <= max ? s : s.substring(0, Math.max(0, max - 1)) + "…";
    }
}
```

`NotificationType { EXPENSE_ADDED, SETTLEMENT_ADDED, PARTICIPANT_JOINED, TODO_ASSIGNED }`.

`Notification` (`@Entity @Table(name="notifications")`): `id`, `@ManyToOne(LAZY) user`, `@ManyToOne(LAZY) trip`, `@Enumerated(STRING) type`, `message` (200), `link` (200), `@Setter readAt`, `createdAt`; costruttore `(User user, Trip trip, NotificationType type, String message, String link, Instant now)`.

`NotificationRepository`: `List<Notification> findTop50ByUserIdOrderByCreatedAtDesc(UUID userId)`, `List<Notification> findTop50ByUserIdAndReadAtIsNullOrderByCreatedAtDesc(UUID userId)`, `long countByUserIdAndReadAtIsNull(UUID userId)`, `Optional<Notification> findByIdAndUserId(UUID id, UUID userId)`, `@Modifying @Query("update Notification n set n.readAt = :now where n.user.id = :userId and n.readAt is null") int markAllRead(UUID userId, Instant now)`.

`NotificationListener` (`@Component`): un metodo per evento, annotato `@TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)` + `@Transactional(propagation = Propagation.REQUIRES_NEW)`; usa `UserRepository`, `TripRepository`, `NotificationRepository`, `Clock`:
- `ExpenseCreated`: per ogni `(userId, share)` in `shareByUserId` con `userId != actorUserId` → riga `EXPENSE_ADDED`, messaggio `NotificationMessages.expense`, link `/trips/{tripId}/expenses/{expenseId}/edit`;
- `SettlementCreated`: a `toUserId` (se non null e ≠ actor) messaggio `settlement(actor, amount, true, fromName)`; a `fromUserId` (idem) `settlement(actor, amount, false, toName)`; link `/trips/{tripId}/balances`;
- `ParticipantJoined`: a ogni `recipientUserIds` ≠ joined → `joined(name)`, link `/trips/{tripId}`;
- `TodoAssigned`: a `assigneeUserId` se non null e ≠ actor → `todo(...)`, link `/trips/{tripId}/lists`.

`NotificationService` (`@Transactional`): `list(userId, boolean unreadOnly)`, `unreadCount(userId)`, `markRead(userId, id)` (404 «Notifica non trovata» se non sua), `markAllRead(userId)`.

`NotificationController` su `/api/notifications`: `GET ?unread=` → `List<NotificationResponse(id, tripId, type, message, link, readAt, createdAt)>`, `GET /unread-count` → `{"count": n}` (record `UnreadCount(long count)`), `PATCH /{id}/read` → 204, `POST /read-all` → 204.

```java
package com.splittrip.photo;

import javax.imageio.IIOImage;
import javax.imageio.ImageIO;
import javax.imageio.ImageWriteParam;
import javax.imageio.ImageWriter;
import javax.imageio.stream.MemoryCacheImageOutputStream;
import java.awt.Color;
import java.awt.Graphics2D;
import java.awt.RenderingHints;
import java.awt.image.BufferedImage;
import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.IOException;

/** Ridecodifica, ridimensiona e riscrive come JPEG senza metadati: nel DB entra solo ciò che produce il server (D-35). */
public final class ImageProcessor {

    public static final int MAX_SIDE = 1600;
    public static final int THUMB_SIDE = 300;
    public static final int AVATAR_SIDE = 256;
    private static final float QUALITY = 0.85f;

    public record Processed(byte[] image, byte[] thumbnail, int width, int height) {}

    private ImageProcessor() {}

    public static Processed process(byte[] input) {
        BufferedImage src = decode(input);
        BufferedImage main = fit(src, MAX_SIDE);
        BufferedImage thumb = fit(src, THUMB_SIDE);
        return new Processed(jpeg(main), jpeg(thumb), main.getWidth(), main.getHeight());
    }

    public static byte[] avatar(byte[] input) {
        BufferedImage src = decode(input);
        int side = Math.min(src.getWidth(), src.getHeight());
        BufferedImage square = src.getSubimage((src.getWidth() - side) / 2, (src.getHeight() - side) / 2, side, side);
        return jpeg(scale(square, AVATAR_SIDE, AVATAR_SIDE));
    }

    private static BufferedImage decode(byte[] input) {
        if (!looksLikeImage(input)) throw new InvalidImageException();
        try {
            BufferedImage img = ImageIO.read(new ByteArrayInputStream(input));
            if (img == null) throw new InvalidImageException();
            return img;
        } catch (IOException e) {
            throw new InvalidImageException();
        }
    }

    /** Tipo dai primi byte: estensione e Content-Type dichiarato non contano. */
    static boolean looksLikeImage(byte[] b) {
        if (b.length < 12) return false;
        boolean jpeg = (b[0] & 0xFF) == 0xFF && (b[1] & 0xFF) == 0xD8;
        boolean png = (b[0] & 0xFF) == 0x89 && b[1] == 'P' && b[2] == 'N' && b[3] == 'G';
        boolean webp = b[0] == 'R' && b[1] == 'I' && b[2] == 'F' && b[3] == 'F' && b[8] == 'W' && b[9] == 'E' && b[10] == 'B' && b[11] == 'P';
        return jpeg || png || webp;
    }

    private static BufferedImage fit(BufferedImage src, int maxSide) {
        int w = src.getWidth(), h = src.getHeight();
        int longSide = Math.max(w, h);
        if (longSide <= maxSide) return scale(src, w, h);
        double k = (double) maxSide / longSide;
        return scale(src, Math.max(1, (int) Math.round(w * k)), Math.max(1, (int) Math.round(h * k)));
    }

    /** Disegna su un'immagine RGB nuova: niente alfa (sfondo bianco), niente metadati. */
    private static BufferedImage scale(BufferedImage src, int w, int h) {
        BufferedImage out = new BufferedImage(w, h, BufferedImage.TYPE_INT_RGB);
        Graphics2D g = out.createGraphics();
        g.setColor(Color.WHITE);
        g.fillRect(0, 0, w, h);
        g.setRenderingHint(RenderingHints.KEY_INTERPOLATION, RenderingHints.VALUE_INTERPOLATION_BILINEAR);
        g.drawImage(src, 0, 0, w, h, null);
        g.dispose();
        return out;
    }

    private static byte[] jpeg(BufferedImage img) {
        ImageWriter writer = ImageIO.getImageWritersByFormatName("jpeg").next();
        ImageWriteParam param = writer.getDefaultWriteParam();
        param.setCompressionMode(ImageWriteParam.MODE_EXPLICIT);
        param.setCompressionQuality(QUALITY);
        ByteArrayOutputStream out = new ByteArrayOutputStream();
        try (MemoryCacheImageOutputStream ios = new MemoryCacheImageOutputStream(out)) {
            writer.setOutput(ios);
            writer.write(null, new IIOImage(img, null, null), param);
        } catch (IOException e) {
            throw new IllegalStateException("Impossibile scrivere il JPEG", e);
        } finally {
            writer.dispose();
        }
        return out.toByteArray();
    }
}
```

```java
@Component
public class RestClientOpenMeteoClient implements OpenMeteoClient {
    private final RestClient rest;
    public RestClientOpenMeteoClient(RestClient.Builder builder) {
        // timeout 3 s: il meteo non deve mai rallentare la panoramica
        var factory = new org.springframework.http.client.JdkClientHttpRequestFactory();
        factory.setReadTimeout(java.time.Duration.ofSeconds(3));
        this.rest = builder.requestFactory(factory).build();
    }
    record GeoResult(BigDecimal latitude, BigDecimal longitude) {}
    record GeoResponse(List<GeoResult> results) {}
    record Daily(List<LocalDate> time, @JsonProperty("weather_code") List<Integer> weatherCode,
                 @JsonProperty("temperature_2m_max") List<BigDecimal> tMax, @JsonProperty("temperature_2m_min") List<BigDecimal> tMin) {}
    record ForecastResponse(Daily daily) {}

    @Override public Optional<Coordinates> geocode(String place) {
        GeoResponse r = rest.get().uri("https://geocoding-api.open-meteo.com/v1/search?name={n}&count=1&language=it", place).retrieve().body(GeoResponse.class);
        if (r == null || r.results() == null || r.results().isEmpty()) return Optional.empty();
        return Optional.of(new Coordinates(r.results().getFirst().latitude(), r.results().getFirst().longitude()));
    }
    @Override public List<DayForecast> forecast(BigDecimal lat, BigDecimal lon) {
        ForecastResponse r = rest.get().uri("https://api.open-meteo.com/v1/forecast?latitude={a}&longitude={b}&daily=weather_code,temperature_2m_max,temperature_2m_min&timezone=auto&forecast_days=16", lat, lon).retrieve().body(ForecastResponse.class);
        if (r == null || r.daily() == null) return List.of();
        List<DayForecast> out = new ArrayList<>();
        for (int i = 0; i < r.daily().time().size(); i++) out.add(new DayForecast(r.daily().time().get(i), r.daily().weatherCode().get(i), r.daily().tMin().get(i), r.daily().tMax().get(i)));
        return out;
    }
}
```

```tsx
type Props = { path: string; alt: string; className?: string }

/** <img> per immagini che richiedono il Bearer: scarica il blob (cache di TanStack Query) e lo mostra con un object URL. */
export function AuthImage({ path, alt, className = '' }: Props) {
  const { data } = useQuery({ queryKey: ['blob', path], queryFn: () => apiBlob(path), staleTime: Infinity, gcTime: 10 * 60_000 })

  useEffect(() => () => { if (url) URL.revokeObjectURL(url) }, [url])
  if (!url) return <span className={`img-placeholder ${className}`} aria-busy="true" aria-label={alt} role="img" />
  return <img src={url} alt={alt} className={className} />
}
```

```ts
import exifr from 'exifr'
export async function readPhotoMeta(file: File) {
  try {
    const [gps, tags] = await Promise.all([exifr.gps(file).catch(() => undefined), exifr.parse(file, ['DateTimeOriginal']).catch(() => undefined)])
    const takenAt = tags?.DateTimeOriginal instanceof Date ? tags.DateTimeOriginal.toISOString() : undefined
    return { takenAt, latitude: gps?.latitude, longitude: gps?.longitude }
  } catch { return {} }
}
export async function downscale(file: File, maxSide = 1600, quality = 0.85): Promise<Blob> {
  const bitmap = await createImageBitmap(file)
  const k = Math.min(1, maxSide / Math.max(bitmap.width, bitmap.height))
  const canvas = document.createElement('canvas')
  canvas.width = Math.round(bitmap.width * k); canvas.height = Math.round(bitmap.height * k)
  canvas.getContext('2d')!.drawImage(bitmap, 0, 0, canvas.width, canvas.height)
  bitmap.close()
  return new Promise((resolve, reject) => canvas.toBlob((b) => (b ? resolve(b) : reject(new Error('Impossibile preparare la foto'))), 'image/jpeg', quality))
}
```
