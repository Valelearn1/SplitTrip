# SplitTrip v3.2 — aggiunte prima del tag · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** importi solo numerici con 2 decimali e tetto 999.999,99, occhiolino sulla password, destinazione reale obbligatoria, «Chi offre?» come offerta vera, password dimenticata via email.

**Architecture:** una funzione pura `sanitizeAmount` e un `AmountField` condiviso nel frontend, limiti uguali nei DTO del backend; `PasswordField` condiviso; la destinazione richiede coordinate nel `TripService` e il servizio dei luoghi dice 503 quando non risponde; il ripristino password è un piccolo sottosistema in `auth` (V9, token hashato, mailer dietro un'interfaccia, email dopo il commit) con due pagine pubbliche.

**Tech Stack:** Spring Boot 4.1 / Java 25, Flyway, `spring-boot-starter-mail` (SMTP Brevo); React 19 + TypeScript, react-hook-form + zod, Vitest + MSW, Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-16-v3.2-aggiunte-prima-del-tag-design.md` (decisioni D-52 agg., D-60, D-61)

## Global Constraints

- Importi: solo cifre e una virgola; massimo 6 cifre intere e 2 decimali; massimo **999.999,99**; messaggio server «Al massimo 999.999,99».
- Errori sempre in Problem Details, mai 500 per input dell'utente.
- Password: 8–72 caratteri, almeno una lettera e una cifra (regole della registrazione).
- Token di ripristino: 32 byte casuali (Base64 URL), solo hash SHA-256 in tabella, validità 30 minuti, monouso; `request` risponde **sempre 204**.
- Email spedita **dopo il commit** (`AfterCommit.run`); credenziali solo in `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM`; il link nel log solo con `MAIL_LOG_LINKS=true` (sviluppo), mai di default.
- Link: `${app.cors.origin}/reimposta-password?token=…`.
- Testi neutri (niente maschile/femminile): «Se non l'hai chiesto tu, ignora questa email.»
- Destinazione: senza coordinate → 400 sul campo `destination` «Scegli la destinazione dall'elenco»; servizio dei luoghi giù → 503 «Ricerca dei luoghi non disponibile, riprova tra poco».
- I commit li fa l'autrice: ogni task finisce con «Puoi committare: `…`» (+ Stage All).

## Review Focus

1. **Incollare o scrivere un importo «all'europea» o «all'americana»** («1.234», «1.234,56», «1,234.56», «€ 12,50»): il campo non deve trasformarlo in un numero diverso da quello inteso → test in Task 2 (`sanitizeAmount`; regola: con virgola e punto, decimale è l'ultimo dei due; con soli punti seguiti da gruppi di 3 cifre sono migliaia; un punto solo con 1–2 cifre è la virgola decimale).
2. **Ripristino chiesto due volte e usato il primo link**: il primo link non deve più funzionare → test in Task 6 (`laSecondaRichiestaAnnullaLaPrima`).
3. **Email con maiuscole o spazi** («  Vale@Example.it ») nel ripristino: deve trovare l'account come fa il login → test in Task 6 (`emailNormalizzataComeAlLogin`).
4. **Viaggio vecchio senza coordinate modificato solo nel nome o nelle date**: deve salvarsi senza chiedere la destinazione → test in Task 4 (`modificaSenzaCambiareDestinazioneNonChiedeCoordinate`).
5. **Importo esattamente 999.999,99 e 0,01**: accettati ovunque; 1.000.000,00 rifiutato → test in Task 1 e Task 2.

```ts
import type { ChangeEventHandler } from 'react'

export const MAX_AMOUNT_CENTS = 99_999_999   // 999.999,99

/**
 * Tiene solo un importo scrivibile: cifre e una virgola, al massimo 6 cifre intere e 2 decimali.
 * Il punto delle migliaia («1.234,56», «1,234.56») si toglie; un punto da solo è la virgola decimale.
 */
export function sanitizeAmount(raw: string): string {
  let s = raw.replace(/[^\d.,]/g, '')
  const lastComma = s.lastIndexOf(','), lastDot = s.lastIndexOf('.')
  if (lastComma >= 0 && lastDot >= 0) {
    const decimal = lastComma > lastDot ? ',' : '.'
    s = s.replace(decimal === ',' ? /\./g : /,/g, '').replace('.', ',')
  } else if (/^\d{1,3}(\.\d{3})+$/.test(s)) {
    s = s.replace(/\./g, '')          // «1.234», «1.234.567»: punti delle migliaia
  } else {
    s = s.replace(/\./g, ',')         // «12.5»: il punto è la virgola decimale
  }
  const [intRaw, ...rest] = s.split(',')
  const intPart = intRaw.replace(/^0+(?=\d)/, '').slice(0, 6)
  if (rest.length === 0) return intPart
  return `${intPart || '0'},${rest.join('').slice(0, 2)}`
}

/** Avvolge l'onChange di un input (anche quello di react-hook-form) ripulendo il valore prima di passarlo. */
export function withAmountSanitizer<P extends { onChange?: ChangeEventHandler<HTMLInputElement> }>(props: P): P {
  return { ...props, onChange: (e) => { e.target.value = sanitizeAmount(e.target.value); props.onChange?.(e) } }
}
```

'€' : currency} />`.
