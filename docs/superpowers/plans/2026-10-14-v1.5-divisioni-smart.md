# SplitTrip v1.5 «Divisioni smart» — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** i soldi del viaggio puntano ai *partecipanti* (anche senza account, rivendicabili), e le spese si dividono anche per peso e per presenza (notti/giorni).

**Architecture:** una migrazione Flyway `V2` rinomina `trip_members` in `participants` e riscrive le chiavi di spese, quote e rimborsi (D-30); due classi pure (`PresenceCalculator`, `WeightedSplitter`) calcolano le quote per `WEIGHT` e `DAYS` senza toccare `BalanceCalculator`; un `ParticipantService` gestisce aggiunta, modifica, uscita (`left_at`) e scollegamento; il frontend replica presenza e divisione pesata in una util testata per l'anteprima nel form.

**Tech Stack:** Spring Boot 4.1 / Java 25 / Hibernate 7 / Flyway / Testcontainers · React 19 / TS / Vite / TanStack Query / RHF + Zod / Vitest + msw.

**Spec:** `docs/superpowers/specs/2026-10-14-v1.5-divisioni-smart-design.md` (le sezioni citate come §N sono di questa spec; la spec v1 è `2026-10-12-splittrip-design.md`).

## Global Constraints

- Soldi: `BigDecimal` scala 2 `HALF_UP`, calcoli in centesimi `long`; mai `double` (CLAUDE.md).
- Schema solo via Flyway, `ddl-auto=validate`; **mai toccare `V1__core.sql`**.
- Ogni service su un viaggio inizia con `TripAccessService.requireMember / requireOrganizer`; l'id utente viene sempre dal token (`@CurrentUserId`).
- Errori sempre in Problem Details, messaggi in italiano, mai stack trace.
- Ovunque nei soldi gli id sono **id di partecipante**; i nomi dei campi lo dicono: `payerId` (partecipante), `participantId`, `fromParticipantId`, `toParticipantId` (§5).
- `participants` non si cancellano mai: uscita = `left_at` (D-30). `requireMember` esclude chi ha `left_at` (§6).
- Date ISO nell'API, italiane a schermo. Accessibilità D-24: mai solo il colore, `aria-label` sui campi numerici, `legend` sui gruppi di radio.
- TDD: test prima del codice. Un commit per task su `main`, messaggio in italiano, **nessuna riga `Co-Authored-By`**; i commit li fa l'autrice (il piano indica il messaggio).
- Suite di riferimento a inizio piano: BE 70 test, FE 20 test, tutti verdi.

## Review Focus

Casi che la spec implica ma che nessun test copriva in prima stesura; ognuno ha ora il suo test nel task indicato.

1. **Rivendicare un posto di un altro viaggio** (`participantId` di un viaggio diverso da quello del codice): deve dare `404`, non collegare l'account a un viaggio in cui non si è → test in Task 5.
2. **Peso enorme o con 3 decimali** (`1000000`, `1.005`): `400` con `errors[0].field` che contiene `weight`, non overflow né arrotondamento silenzioso → test in Task 3.
3. **Tutti con 0 notti** (spesa `DAYS` in cui ogni incluso ha `weight: 0`): `400` «Almeno un partecipante deve avere un peso maggiore di zero», non una divisione per zero → test in Task 3.
4. **Token ancora valido dopo lo scollegamento**: l'utente scollegato riceve `403` alla richiesta successiva sul viaggio → test in Task 4.
5. **Modifica di un partecipante che ha lasciato il viaggio** (`PATCH /participants/{pid}` con `left_at` ≠ null): `404`, non una riattivazione silenziosa → test in Task 4.

```sql
-- v1.5 «Divisioni smart» (D-30, D-31, D-33; spec 2026-10-14 §3)
-- 1. trip_members → participants: identità economica, anche senza account
ALTER TABLE trip_members RENAME TO participants;
ALTER TABLE participants RENAME CONSTRAINT trip_members_unique TO participants_user_unique;
ALTER TABLE participants
    ADD COLUMN display_name   VARCHAR(40),
    ADD COLUMN default_weight NUMERIC(6, 2) NOT NULL DEFAULT 1,
    ADD COLUMN arrival_date   DATE,
    ADD COLUMN departure_date DATE,
    ADD COLUMN left_at        TIMESTAMPTZ;
UPDATE participants p SET display_name = u.display_name FROM users u WHERE u.id = p.user_id;
ALTER TABLE participants ALTER COLUMN display_name SET NOT NULL;
ALTER TABLE participants ALTER COLUMN user_id DROP NOT NULL;
ALTER TABLE participants
    ADD CONSTRAINT participants_weight_positive CHECK (default_weight > 0),
    ADD CONSTRAINT participants_dates CHECK (arrival_date IS NULL OR departure_date IS NULL OR departure_date >= arrival_date);
CREATE INDEX idx_participants_trip ON participants (trip_id);

-- 2. Orfani: utenti usciti dal viaggio in v1 ma ancora citati nei soldi (anche nel cestino) → riga con left_at
INSERT INTO participants (id, trip_id, user_id, display_name, role, joined_at, left_at)
SELECT gen_random_uuid(), x.trip_id, x.user_id, u.display_name, 'MEMBER', now(), now()
FROM (
    SELECT trip_id, payer_id AS user_id FROM expenses
    UNION SELECT e.trip_id, s.user_id FROM expense_shares s JOIN expenses e ON e.id = s.expense_id
    UNION SELECT trip_id, from_user_id FROM settlements
    UNION SELECT trip_id, to_user_id FROM settlements
) x
JOIN users u ON u.id = x.user_id
WHERE NOT EXISTS (SELECT 1 FROM participants p WHERE p.trip_id = x.trip_id AND p.user_id = x.user_id);

-- 3. expenses: pagante → partecipante; S2 valuta/tasso/importo base; S4 tipi di divisione
ALTER TABLE expenses ADD COLUMN payer_participant_id UUID REFERENCES participants (id);
UPDATE expenses e SET payer_participant_id = p.id FROM participants p WHERE p.trip_id = e.trip_id AND p.user_id = e.payer_id;
ALTER TABLE expenses ALTER COLUMN payer_participant_id SET NOT NULL;
ALTER TABLE expenses DROP COLUMN payer_id;
ALTER TABLE expenses
    ADD COLUMN currency    VARCHAR(3),
    ADD COLUMN fx_rate     NUMERIC(18, 8) NOT NULL DEFAULT 1,
    ADD COLUMN amount_base NUMERIC(12, 2),
    ADD COLUMN day_basis   VARCHAR(8);
UPDATE expenses e SET currency = t.currency, amount_base = e.amount FROM trips t WHERE t.id = e.trip_id;
ALTER TABLE expenses ALTER COLUMN currency SET NOT NULL, ALTER COLUMN amount_base SET NOT NULL;
ALTER TABLE expenses DROP CONSTRAINT expenses_split_type_check;
ALTER TABLE expenses
    ADD CONSTRAINT expenses_split_type_check CHECK (split_type IN ('EQUAL', 'CUSTOM', 'WEIGHT', 'DAYS')),
    ADD CONSTRAINT expenses_day_basis_check CHECK (day_basis IN ('DAYS', 'NIGHTS')),
    ADD CONSTRAINT expenses_day_basis_only_for_days CHECK ((split_type = 'DAYS') = (day_basis IS NOT NULL));

-- 4. expense_shares: quota → partecipante; weight = input usato (peso o notti/giorni)
ALTER TABLE expense_shares ADD COLUMN participant_id UUID REFERENCES participants (id);
UPDATE expense_shares s SET participant_id = p.id
FROM expenses e, participants p
WHERE e.id = s.expense_id AND p.trip_id = e.trip_id AND p.user_id = s.user_id;
ALTER TABLE expense_shares ALTER COLUMN participant_id SET NOT NULL;
ALTER TABLE expense_shares DROP CONSTRAINT expense_shares_unique;
ALTER TABLE expense_shares DROP COLUMN user_id;
ALTER TABLE expense_shares
    ADD CONSTRAINT expense_shares_unique UNIQUE (expense_id, participant_id),
    ADD COLUMN weight NUMERIC(8, 2) CHECK (weight >= 0);

-- 5. settlements: da/a → partecipanti
ALTER TABLE settlements
    ADD COLUMN from_participant_id UUID REFERENCES participants (id),
    ADD COLUMN to_participant_id   UUID REFERENCES participants (id);
UPDATE settlements s SET from_participant_id = pf.id, to_participant_id = pt.id
FROM participants pf, participants pt
WHERE pf.trip_id = s.trip_id AND pf.user_id = s.from_user_id
  AND pt.trip_id = s.trip_id AND pt.user_id = s.to_user_id;
ALTER TABLE settlements ALTER COLUMN from_participant_id SET NOT NULL, ALTER COLUMN to_participant_id SET NOT NULL;
ALTER TABLE settlements DROP CONSTRAINT settlements_distinct_users;
ALTER TABLE settlements DROP COLUMN from_user_id, DROP COLUMN to_user_id;
ALTER TABLE settlements ADD CONSTRAINT settlements_distinct_participants CHECK (from_participant_id <> to_participant_id);
```

```java
package com.splittrip.trip;

import com.splittrip.user.User;
import jakarta.persistence.*;
import lombok.AccessLevel;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

import java.math.BigDecimal;
import java.time.Instant;
import java.time.LocalDate;
import java.util.UUID;

/** Chi partecipa al viaggio: identità economica (soldi) e di accesso (user, se ha un account). Non si cancella mai: chi esce ha leftAt (D-30). */
@Entity
@Table(name = "participants")
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
public class Participant {

    @Id
    @GeneratedValue(strategy = GenerationType.UUID)
    private UUID id;

    @ManyToOne(fetch = FetchType.LAZY, optional = false) @JoinColumn(name = "trip_id") private Trip trip;
    @Setter @ManyToOne(fetch = FetchType.LAZY) @JoinColumn(name = "user_id") private User user; // null = senza account
    @Setter @Column(name = "display_name", nullable = false, length = 40) private String displayName;
    @Enumerated(EnumType.STRING) @Column(nullable = false, length = 16) private MemberRole role;
    @Setter @Column(name = "default_weight", nullable = false, precision = 6, scale = 2) private BigDecimal defaultWeight = BigDecimal.ONE;
    @Setter @Column(name = "arrival_date") private LocalDate arrivalDate;
    @Setter @Column(name = "departure_date") private LocalDate departureDate;
    @Column(name = "joined_at", nullable = false) private Instant joinedAt;
    @Setter @Column(name = "left_at") private Instant leftAt;

    public Participant(Trip trip, User user, String displayName, MemberRole role, Instant joinedAt) {
        this.trip = trip;
        this.user = user;
        this.displayName = displayName;
        this.role = role;
        this.joinedAt = joinedAt;
    }

    public boolean isOrganizer() { return role == MemberRole.ORGANIZER; }
    public boolean hasAccount() { return user != null; }
    public boolean hasLeft() { return leftAt != null; }
    /** Id dell'utente senza caricare l'entità (null se senza account). */
    public UUID userId() { return user == null ? null : user.getId(); }
}
```

```java
package com.splittrip.expense;

import java.time.LocalDate;
import java.time.temporal.ChronoUnit;

/** Giorni o notti di presenza: intersezione tra le date del partecipante e quelle del viaggio (D-31). */
public final class PresenceCalculator {

    private PresenceCalculator() {}

    public static int count(LocalDate tripStart, LocalDate tripEnd, LocalDate arrival, LocalDate departure, DayBasis basis) {
        LocalDate from = arrival == null || arrival.isBefore(tripStart) ? tripStart : arrival;
        LocalDate to = departure == null || departure.isAfter(tripEnd) ? tripEnd : departure;
        if (to.isBefore(from)) {
            return 0;
        }
        int nights = (int) ChronoUnit.DAYS.between(from, to);
        return basis == DayBasis.NIGHTS ? nights : nights + 1;
    }
}
```

```java
package com.splittrip.expense;

import com.splittrip.common.BadRequestException;
import com.splittrip.expense.BalanceCalculator.ShareInput;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.UUID;

/** Divide un importo in proporzione ai pesi; i centesimi di resto vanno a chi ha la parte frazionaria più alta, poi per id. */
public final class WeightedSplitter {

    private WeightedSplitter() {}

    public static List<ShareInput> split(BigDecimal total, Map<UUID, BigDecimal> weights) {
        BigDecimal sumWeights = weights.values().stream().reduce(BigDecimal.ZERO, BigDecimal::add);
        if (weights.isEmpty() || sumWeights.signum() <= 0) {
            throw new BadRequestException("Almeno un partecipante deve avere un peso maggiore di zero");
        }
        List<UUID> ids = weights.keySet().stream().sorted().toList();
        long totalCents = BalanceCalculator.cents(total);
        long[] floor = new long[ids.size()];
        BigDecimal[] fraction = new BigDecimal[ids.size()];
        long assigned = 0;
        for (int i = 0; i < ids.size(); i++) {
            // quota esatta in centesimi, con 10 decimali di precisione per confrontare i resti
            BigDecimal exact = BigDecimal.valueOf(totalCents).multiply(weights.get(ids.get(i)))
                    .divide(sumWeights, 10, RoundingMode.DOWN);
            floor[i] = exact.setScale(0, RoundingMode.DOWN).longValueExact();
            fraction[i] = exact.subtract(BigDecimal.valueOf(floor[i]));
            assigned += floor[i];
        }
        long remainder = totalCents - assigned;
        List<Integer> order = new ArrayList<>();
        for (int i = 0; i < ids.size(); i++) order.add(i);
        order.sort(Comparator.<Integer, BigDecimal>comparing(i -> fraction[i]).reversed().thenComparing(i -> ids.get(i)));
        for (int k = 0; k < remainder; k++) {
            floor[order.get(k)]++;
        }
        List<ShareInput> shares = new ArrayList<>(ids.size());
        for (int i = 0; i < ids.size(); i++) {
            shares.add(new ShareInput(ids.get(i), BalanceCalculator.eur(floor[i])));
        }
        return shares;
    }
}
```

```ts
import { differenceInCalendarDays, parseISO } from 'date-fns'
import type { DayBasis, ExpenseCategory } from '../api/types'

/** Giorni o notti di presenza: intersezione tra le date del partecipante e quelle del viaggio (D-31). Specchio di PresenceCalculator. */
export function presence(
  trip: { startDate: string; endDate: string },
  p: { arrivalDate: string | null; departureDate: string | null },
  basis: DayBasis,
): number {
  const start = parseISO(trip.startDate)
  const end = parseISO(trip.endDate)
  const from = p.arrivalDate && parseISO(p.arrivalDate) > start ? parseISO(p.arrivalDate) : start
  const to = p.departureDate && parseISO(p.departureDate) < end ? parseISO(p.departureDate) : end
  if (to < from) return 0
  const nights = differenceInCalendarDays(to, from)
  return basis === 'NIGHTS' ? nights : nights + 1
}

/** Divide un totale in centesimi in proporzione ai pesi; resto maggiore, poi ordine di id. Specchio di WeightedSplitter. */
export function splitByWeight(totalCents: number, weights: { id: string; weight: number }[]): Map<string, number> {
  const sorted = [...weights].sort((a, b) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0))
  const sum = sorted.reduce((s, w) => s + w.weight, 0)
  const result = new Map<string, number>()
  if (sum <= 0) {
    for (const w of sorted) result.set(w.id, 0)
    return result
  }
  const exact = sorted.map((w) => (totalCents * w.weight) / sum)
  const floors = exact.map((x) => Math.floor(x + 1e-9))
  let remainder = totalCents - floors.reduce((a, b) => a + b, 0)
  const order = sorted.map((_, i) => i).sort((i, j) => exact[j] - floors[j] - (exact[i] - floors[i]) || (sorted[i].id < sorted[j].id ? -1 : 1))
  for (const i of order) {
    if (remainder <= 0) break
    floors[i]++
    remainder--
  }
  sorted.forEach((w, i) => result.set(w.id, floors[i]))
  return result
}

export function defaultBasis(category: ExpenseCategory): DayBasis {
  return category === 'LODGING' ? 'NIGHTS' : 'DAYS'
}
```
